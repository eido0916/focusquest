## v001の制作履歴

集中のソロ戦闘、パーティー戦闘、ステージ冒険に共通の原画エフェクトを追加した。
男女は同じエフェクトを使い、各キャラクターの既存スキル原画の発生イベントに同期する。

| 役職 | 色・演出 |
| --- | --- |
| 剣士 | 青白い三日月状の蓄力斬撃 |
| 拳闘士 | 翡翠色の旋風と風圧 |
| 侍 | 桜色の鋭い連続居合 |
| 重騎士 | 金・土色の地面を砕く衝撃 |
| 忍者 | 紫の影と瞬身の突き筋 |
| アサシン | 紅紫の短剣突きとクリティカル閃光 |
| 弓使い | 緑の矢と三段の射線 |
| 魔法使い | 白水色の氷柱と氷片 |
| ガンナー | 琥珀色の銃火・三段の弾道 |
| 魔剣士 | 紫白の雷剣と落雷 |
| 陰陽師 | 朱色の符と金色の封陣 |
| 鎌使い | 紫の冥月と魂の残光 |
| 天使 | 白金の聖光・羽・光輪 |
| 悪魔 | 紅紫の獄炎 |
| ドラゴンナイト | 橙金の竜炎と竜の横顔 |
| バーサーカー | 赤い裂斬と地割れ |

各役職12枚（最後は透明）、計192枚。範囲用の原画サイズは1536×256pxで、
既存素材と同じ2pxの論理格子を使用する。128×128のキャラクター原画は保持する。
各原画を独立して描画しており、再生時は画像の切り替えだけを行う。
回転、縦横別の伸縮、補間、クロスフェード、透明度の連続変更は使用しない。

キャラクターの実際の座標差分に発生位置を追従させ、画面右端でクリップする。
原画は原点から長く描かれており、表示は論理1pxを整数個の物理ピクセルに揃えた最近傍法。
極端に横長の画面では、完成原画を隣の座標にも配置して右端まで覆う（画像の伸縮はしない）。
スキルの発生前はキャラクター近辺で蓄力し、発生時から右端まで攻撃を表示する。
弓・銃は3回の発射イベントにそれぞれ別の発射原画を対応させる。
冒険では既存仕様に合わせ、動作原画の時間をスキルの行動時間に対応させる。
エフェクトは表示のみで、従来のダメージ・命中・報酬・当たり判定を変更しない。
ソロ・パーティーの画像キャッシュは各ゲーム内で管理し、過去に使用した全役職の
大きな透過原画をFlameのグローバルキャッシュに蓄積しない。
