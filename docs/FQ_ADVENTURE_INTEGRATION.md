# FQ 冒険の統合

開発者の playable_stage（9章・36ステージ）を、FQ の「冒険」タブの標準画面に統合した。

- ステージ選択は青いコマンド窓、金の装飾枠、羊皮紙、章ごとの風景を使用する。各章は4ステージ、4番目にボスが登場する。
- FQで選択中の仲間・性別を使用する。開発者の戦闘バランスを基準に、レベルと装備によるHP・攻撃力・素早さの増加分を加算する。防御力・会心率の追加連携は行っていない。
- 対応する原画は男女各10職。陰陽師・天使は魔法使い、鎌使いはアサシン、悪魔は魔剣士、ドラゴンナイトは重騎士、バーサーカーは剣士の原画を使用し、画面に案内を表示する。原画の変形・補間や元素材の上書きはしない。
- クリア済みステージを `clearedPlayableStages` に保存する。従来のセーブデータには空集合を補完する。開発者版と同じく、全ステージを選択可能で追加の通貨・装備報酬はない。
- 集中と冒険の同時開始、戦闘中の仲間・装備変更を防ぐ。
- 従来の5ステージ冒険・報酬・進行中データは「以前の冒険の書」から利用できる。
- Android用ビルドはデスクトップ用ディレクトリをステージングコピーから除外し、Windowsのデスクトッププラグイン用シンボリックリンク設定に依存しない。

統合テストで旧データ互換性、保存失敗後の再試行、再起動後のクリア記録、女性弓使いでの開始、成長・装備反映、集中との排他を確認する。ステージ選択は320×568、390×844、844×390で検証する。
