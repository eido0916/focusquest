# 推奨レベルの計測（2026-10-12）

全36ステージ×男女32キャラクターを対象に183,984戦を実施。実装と同じ戦闘モデル、攻撃・スキル・敵の原画JSONにある命中タイミングとワールド座標を使用した。60fps、最大300秒、通常攻撃とスキルを可能になり次第使用する操作をモデル化している。

検索はシード0〜11で10勝以上、確定時は別シード1000〜1039で32勝以上（80%）となるレベルを職業・性別ごとに確認。表示する共通推奨値はそれらの最大値。手動操作の遅れやスキル温存は含まず、勝利の保証ではない。個別結果は `stage_balance_v001.json` に保存。

敵の強さは従来の固定値を維持し、表示の推奨レベルを変えても敵のHPや攻撃力が変わらないよう `difficultyLevel` を分離した。
