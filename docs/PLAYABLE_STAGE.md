# Flutter版 プレイアブルステージ

視認性のため、HP文字は11〜12pxの白文字（プレイヤーは黒い文字影付き）で表示します。HPバーの短さとボスの大きい金色バーは維持します。背景だけに15%の黒い陰影を重ね、原画のキャラクターは元の明るさ・配色で描画します。画面に余裕がある場合は整数倍でキャラクターを大きく表示します。攻撃・スキルは待機中も不透明な赤・青を維持し、スキルボタン内に充填数・行動中・発動可能を表示します。

HPはプレイヤー・各敵・ボスの頭上に配置し、原画の表示位置とワールド座標に追従します。元画像の透明画素を読み取って表示の上端を取得するだけで、原画は変更しません。通常の敵は幅64・太さ3、ボスだけ幅128・太さ6の金色、プレイヤーは幅96・太さ3の水色バーです。バー同士の重なりは上下にずらして避け、倒した敵のHPは消します。上部の紺色の帯と戦闘エリアの装飾枠はなくし、上部操作は背景上の白いアイコンと暗い丸背景で表示します。

FlutterのCanvasとWidgetで動作するアプリです。ホームの「冒険に出発する」からステージ選択へ直接進みます。単独デモはキャラクター選択から起動し、選択したキャラクターでステージに挑みます。

冒険UIはホームと共通の紺・金・羊皮紙の装飾枠を使用します。ステージ選択は「冒険の書」と章ごとの背景、通常ステージの羊皮紙カード、ボスの紺色カードで構成します。戦闘の開始／休憩／結果パネルも同じ装飾枠で統一しています。戦闘中のステージ名・走行などの状況メッセージ・専用の操作枠は表示せず、赤い攻撃ボタンと青いスキルボタンを画面右下へ直接並べます。ボタンの進捗リングで行動時間・スキルの充填を確認できます。戦闘のキャラクター・飛び道具は既存のドット絵とポイントサンプリングのままです。ボタンが敵を隠さないよう戦闘位置を上へ調整し、ボタンの下には既存背景の地面を同じ倍率で繰り返し描画します。テーマは冒険画面内だけに適用します。

通常行動時間は100÷素早さ、スキルはその1.75倍です。原画タイムラインの保持時間を行動時間に合わせて変更し、補間画像は作りません。攻撃発生位置は各素材のイベントの時間比率に合わせます。通常攻撃は攻撃力、スキルは攻撃力の4倍を基礎ダメージとし、複数回斬撃・射撃する原画でもゲームの命中判定は1行動につき1回です。

近接攻撃・近接スキルでは対象の手前へ移動し、元の命中原画が表示される前に接近を完了します。モンスターもプレイヤーの現在位置へ近づき、攻撃後に配置位置へ戻ります。通常敵と3倍サイズのボスは画面内の原画サイズに合わせて間合いを分け、相手を通り抜けません。攻撃開始時の対象を行動終了まで保持するため、撃破直後に次の敵へ飛ぶこともありません。忍者の瞬身突きのJSONにある座標オフセットも間合い計算に含めます。命中後のダメージやMISSは対象の頭上に表示します。すべてワールド座標の移動で、原画画像は変更しません。

弓使い・ガンナー・魔法使いは通常攻撃もスキルも左側の配置位置から発射します。忍者の通常攻撃もその場から手裏剣を投げます。原画JSONの発射イベントに合わせ、固定のドット絵の矢・弾・火球・氷・手裏剣をワールド座標で移動させます。飛び道具が対象の現在位置に到達した瞬間に命中・クリティカル・ダメージ・ゲージ・効果音を確定し、命中時に固定のドット絵の衝撃を表示します。外れた飛び道具は敵を通り過ぎます。弓使いとガンナーのスキルは原画の3発の発射イベントを使い、従来のスキル総威力を3発へ分配します。各発でクリティカルを判定し、対象は発射した行動の敵に固定します。発射後に行動が終了しても飛び道具は継続し、一時停止時は移動も命中判定も停止します。キャラクターPNGの加工や回転、変形、画像補間は行いません。

従来の4エリア（草原・幽霊船・火山・魔王城）の第1フェーズはスライム2体、第2フェーズはゴブリン3体、第3フェーズはドラキュラ3体が同時に登場します。4の倍数のステージでは最後をボス1体＋取り巻きゴブリン2体に置き換えます。各敵が個別のHP・攻撃待ち時間・原画再生・撃破状態を持ち、全員の撃破原画が終了してから次のフェーズへ進みます。攻撃は手前の生存敵を自動で狙い、余剰ダメージは次の敵へ持ち越しません。ボスの描画倍率はプレイヤーの3倍で、縮小画面でも64px論理格子の整数倍・ポイントサンプリングを維持します。

フェーズ間は走り続け、赤い丸ボタンで通常攻撃、青い丸ボタンでスキルを行います。通常攻撃を3回命中させると各職業のスキルが使えます。行動中は両ボタンを無効にし、周囲のリングで次の行動までの進行を表示します。3フェーズをクリアすると1.4秒後にステージ選択へ戻り、選択したカードにCLEARを表示します。敗北時は同じステージを再挑戦するか、選択画面へ戻れます。各挑戦は選択キャラクターのHP全回復・ゲージ0・第1フェーズから開始します。

CLEAR表示は選択画面が開いている間保持します。これは固定ステータスの操作デモで、集中による成長や報酬の保存との連携は後続工程です。

通常攻撃の命中率は90%、命中した場合のクリティカル率は20%でダメージ2倍です。スキルは必中で、同じクリティカル判定を行います。空振りではスキルゲージが増えません。敵の攻撃は命中率85%、クリティカル率10%、ダメージ1.5倍（四捨五入）です。命中判定は攻撃が発生する瞬間に一度だけ行い、画面にMISSやCRITICALを表示します。

通常戦とボス戦にオリジナルのチップチューンBGMをループ再生します。斬撃・スキル・命中・クリティカル・空振り・被弾・敵撃破・勝利・敗北の9種類の効果音を鳴らします。画面右上のスピーカーボタンで音を切り替え、一時停止・バックグラウンド移行ではBGMと効果音も停止します。ステージを離れると音声プレイヤーを破棄します。Androidの効果音はBGMの音声フォーカスを奪わない設定です。

音源は `scripts/build-stage-audio.py` がNumPyで合成した16bit/44.1kHz WAVで、第三者の録音や既存曲を使用していません。通常戦132BPM、ボス戦156BPMです。音源と再生成用のmanifestは `mobile/assets/audio/playable_stage/` にあります。再生成にはPythonとNumPyが必要です。再生には `audioplayers 6.1.0` を使用しています。

原画PNGをJSONの24fpsタイムラインに従って切り替え、保持中は同一画像を表示します。キャラクターの拡大は64px論理格子を物理ピクセルで整数倍、ポイントサンプリングで描画します。移動はワールド座標で管理します。素材を変形・補間せず、敵の消滅も描いた原画を一度だけ再生します。`scripts/package-flutter-stage.py` がv013の使用素材（117動作・879原画、旧剣士エイリアスを含む）をコピーし、PNGとRGBAのSHA-256を検証してmanifestに保存します。実行時は選択キャラクターとステージ内の敵の素材だけ読み込みます。待機素材のない職業は通常攻撃の最初の構え原画を保持します。元素材は変更しません。
