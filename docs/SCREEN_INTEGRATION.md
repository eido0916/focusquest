# ホーム・集中・プレイアブルステージ統合

2026-10-11。通常起動は `mobile/lib/main.dart`。

## 連携

- ホームの冒険ボタンと下部の冒険タブは、GameControllerを共有する同じステージ選択へ進む。
- 集中成功による成長と装備、選択中の職業・性別を既存の戦闘キャラクター変換で引き継ぐ。
- 集中中は出発できない。戦闘画面を閉じると冒険中の制限を解除する。
- 勝利後はステージ選択へ戻り、端末内にクリア記録を保存する。失敗時は再試行ボタンを表示し、保存完了まで次の出発を止める。
- 以前の5ステージの自動戦闘と保存データは一覧末尾の「以前の冒険の書」から利用できる。
- 原画・アニメーション・戦闘ロジック・音声は変更していない。
- プレイアブルステージのポイント・装備報酬は既存仕様どおり付与しない。
