# 集中の章進行

集中で達成した時間を端末内に保存します。新しい集中は保存された経過秒から続きます。キャンセル・未達成は章の時間に加算しません。旧データは第一章の0秒から開始します。

- 第一章・草原：25分で冒険第一章と同じゴブリンキングが出現。5分間戦い、30分の境界で撃破します。
- 第二章・幽霊船：第一章撃破の直後に新作背景 `ghost_ship_focus_v002.png` へ切り替えます。さらに25分で冒険第二章と同じ騎乗デュラハンが出現。5分で撃破します。
- 第三章以降は未指定のため、第二章の幽霊船で同じ25分＋5分の周期を続けます。
- 標準の30分集中で一周期。例えば25分集中を達成した場合、次の5分集中でボス戦を完了できます。タイマーの指定時間は変更しません。

ソロ・パーティーのどちらも同じ経過時間で背景とボスを決定します。画面を消した後、タイマーへ戻った後、再起動後も保存済み開始時刻とセッションの章開始秒から復元します。報酬確定は既存の一度だけ適用する保存処理を使います。

ボスのHPは残り戦闘秒で減少し、通常攻撃やスキルでは5分より早く撃破できません。5分の境界で撃破を一度だけ記録します。ソロではセッション終了直前の撃破原画を表示してから結果へ戻ります。

既存のv013原画PNG・24fpsタイムラインを使用し、移動・攻撃・撃破を選択します。回転、変形、フェードは加えません。追加背景は静止画で、元の背景素材は保持します。独立した冒険の書のステージクリア記録は引き続き手動の冒険で獲得します。
