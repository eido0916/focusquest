# 端末内AIのスペック目安

FocusQuestの「80文字以内のタスクを6分野へ分類する」用途を想定した設計上の目安です。選ぶモデル・量子化・推論エンジン・同時実行アプリで必要量は変わります。まだこのPCで実モデルを動かした性能測定は行っていません。

|端末|試用の目安|余裕を持つ目安|
|---|---|---|
|Windows PC|メモリ8GB、小型・量子化モデル|メモリ16GB以上|
|Androidスマホ|メモリ6GB程度で小型モデルから検証|メモリ8GB以上|

これらは端末全体のメモリ容量です。AIが追加で消費するメモリと区別してください。Googleは最適化されたGemma 3nについて、E2Bは最小約2GB、E4Bは最小約3GBのメモリで動作すると説明しています。OSとFocusQuest、画像、他アプリのためのメモリはさらに必要です。この値はどの推論エンジンでも同じになる保証ではありません。

モデルファイルの保存にも空き容量が必要です。小型モデルでも数GB程度の空きを見込み、具体的な必要量はモデル選定時にファイル容量と照合します。PCではCPUのみで推論できるエンジンもあり、専用GPUが必須とは限りません。処理速度は別途測定が必要です。

今回確認したPCはAMD Ryzen 7 7735HS（8コア）、OSが認識する物理メモリ約30.8GB、AMD Radeon内蔵グラフィックスです。小型モデルの試用には十分なメモリの余裕があると考えられますが、日本語タスクの分類精度と待ち時間は未測定です。

Gemini API版はAI処理をクラウドで実行するため、端末内モデル用のメモリ・保存領域は不要です。通信とGemini APIキーが必要です。
