# 集中冒険のドット絵表示

集中中の戦闘演出とパーティー集中は、ステージ冒険と同じ原画素材を使用する。
剣士・拳闘士・侍・重騎士・忍者・アサシン・弓使い・魔法使い・ガンナー・魔剣士・陰陽師・鎌使い・天使・悪魔・ドラゴンナイト・バーサーカーの男女32体に対応。
走行・通常攻撃・スキルを職業と性別に合わせて切り替える。

全16職業はそれぞれの走行・通常攻撃・スキル原画を使用する。未知の職業IDのみ男剣士へフォールバックする。冒険・集中・パーティーは共通の対応表を使用する。

128×128の完成済み透過PNGと24fpsの原画保持タイムラインをそのまま読み込む。
集中中の単独キャラクターは全動作で同じ表示倍率（64px論理格子の1ドットを3px）を使用し、ポイントサンプリングで描画する。
画像の回転・パーツ変形・補間・クロスフェードは行わず、タイムラインの座標差分をワールド座標として描画する。
通常攻撃の判定と自動スキルの最初の判定は原画メタデータのイベント時刻に合わせる。
集中のEXP報酬やタイマーの終了日時は従来の処理を使用する。

`scripts/package-focus-pixel-timing.ps1`で原画メタデータから集中戦闘用の時間定義を再生成できる。
素材追加時は`PixelBattleAssets.roles`とこの生成スクリプトを更新する。
`scripts/package-role-skill-bindings.ps1`でエフェクトの対応メタデータも再生成できる。過去の原画PNG・制作素材には変更を加えない。

16役職に固有の原画スキルエフェクトを使用する。追加6職業も専用キャラクター原画のイベント時刻に合わせて表示する。詳細は[ROLE_SKILL_EFFECTS.md](ROLE_SKILL_EFFECTS.md)。

背景は新規制作した`mobile/assets/images/ui/forest_meadow_pixel_v001.png`を使用する。
ソロ・パーティー・ソロ読み込み中の表示まで同じ森と草原のドット絵に統一。
描画は最近傍法で縦横比を維持し、ソロのスクロールは原画像の画素単位に揃える。
制作プロンプトと仕様は`art/focus_background_pixel_v001/`に保存。
以前の手描き風背景は制作履歴として保持する。
