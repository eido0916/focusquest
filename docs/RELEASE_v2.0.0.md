# FocusQuest v2.0.0

冒険の戦闘画面を整理し、キャラクターと操作を見やすくした更新です。v1.0.0の集中タイマー・育成・全36ステージ・オンラインパーティー機能を引き継ぎます。

## v1.0.0からの変更

- 冒険のキャラクター表示を拡大。遠距離エフェクトは従来の表示倍率を維持しました。
- ステージとフェーズの表示を簡潔にし、攻撃・スキルボタンを小型化。スキルの蓄積量を円形ゲージで表示します。
- 戦闘からの撤退を一時停止画面へ移しました。
- 集中・パーティー戦闘の描画をステージ内へ制限し、画面外のキャラクターが余白にはみ出す問題を修正しました。
- Android用のFlutter SDK検出と、USB接続端末への更新インストール・起動スクリプトを追加しました。
- ドット絵の原画PNGを切り替えるアニメーション方式と既存素材・制作履歴を保持しています。

## 新規インストール用APK

`FocusQuest-v2.0.0-android-arm64.apk` は64bit ARM Android端末向けのRelease APKです。アプリのバージョンは **2.0.0**、ビルド番号は **2**。仮設の開発者ツールを非表示にしています。

**このAPKは新規インストール用です。今回の署名はv1.0.0と異なるため、v1.0.0へ上書きインストールできません。** アプリIDは同じなのでv1.0.0との共存もできません。端末内の記録を保持するため、既存アプリを削除しないでください。アンインストールすると端末内の記録は失われます。v1.0.0から保存データを引き継ぐ更新用APKは今回提供しません。

開発用署名鍵で署名しており、ストア配布用署名ではありません。APKのSHA-256は添付の `SHA256SUMS.txt` で確認できます。

GitHubの「Source code」は、このタグのソース一式です。今回の添付バイナリはAndroid版です。
