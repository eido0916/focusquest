# 拳闘士の添付スプライト走行

**後続の指定で通常走行をスキル前原画へ変更しました。現行仕様は[BOXER_RUN_FROM_SKILL.md](BOXER_RUN_FROM_SKILL.md)を参照してください。以下は添付走行シート版の制作履歴です。**

2026-10-10。男性拳闘士の既存戦闘コンポーネントへ実装。画像生成・姿勢の変形・補間は使用しない。

最終順序は **1→2→3→4→1**。各1/12秒、12FPS、1周1/3秒。4→1は伸展姿勢同士の接続で、5→1にあった前脚の戻りを減らす。10原画すべて個別PNGを保持する。

元の10コマは左右の脚を明確に交換した完全な走行周期ではない。3への腕の変化や脚の位相には素材由来の制約が残る。新しい絵を作らずに、完全な左右交互の走行を実現したとは判断しない。

## 切り出しと表示

5等分は行わない。alpha>4の連結領域で5体を識別し、小さな孤立画素は近傍の輪郭へ所属させる。alpha 1〜4の縁は輪郭から所属を拡張し、元のRGBAをコピーする。第1シートの4・5の非常に薄い縁は接触するが、実体輪郭は独立している。全非透明画素の所属、切り出しの画素一致、保存アトラスの画素一致を検証する。

共通キャンバス640×768、腰の横基準x=320、実体靴底y=680。画像ごとの拡縮をせず整数ピクセル平行移動で配置する。身体の自然な姿勢差は保持する。表示倍率は従来の拳闘士・前蹴りと同じ215/328/2。ゲーム座標(345,405)固定。走行中の画像パーツ変形・クロスフェード・中間画像生成はない。

`run.json`に切り出し範囲・配置・採否・保持時間・24FPS用原画番号を記録。24FPS用8連番は各原画を2回ずつ複製し、RGBA完全一致を検証。移動の画像加工はなく、ワールド座標イベントは空。

## 既存システムへの接続

`BoxerRunAssets`がrun.png/run.jsonを一度読み込む。通常攻撃アトラスは保持し、走行だけを専用アトラスへ変更。Skill（前蹴り）>Attacking>Runningの既存優先順位を保持。攻撃・スキルから復帰する際、走行アニメーション・キャンバスサイズ・足元アンカーを復元する。

走行位相は背景と同じ`backgroundTravelSeconds`から決定し、停止したゲーム時計やリプレイに追従する。背景速度108px/秒は変更しない。足滑りを完全に消すための新しい脚位相は生成しない。敵生成・ダメージ・報酬・他職業の素材は変更しない。

## 確認

変更コードのDart解析は問題なし。新しい走行テストが通過し、ゲーム内の2周、固定位置と表示倍率、背景時計停止、通常攻撃の2ヒット、スキルの1ヒット、優先順位、走行復帰を検証。Flutter戦闘画面のPNGも出力。

最終4原画版で`boxer_run_test.dart`、`boxer_front_kick_test.dart`、`boxer_wind_effect_test.dart`の計5件と、`boxer_animation_test.dart`の実戦闘ウィジェット1件が通過（計6件）。

Android 16のTB373FUで専用プレビューを別アプリID `dev.focusquest.focusquest.boxerrunpreview` としてビルド・インストール・起動。既存アプリの保存データを使用しない。実機スクリーンショット・録画を取得。長時間安定性・性能計測は未実施。

関連テストの既存失敗：`boxer_animation_test.dart`の「reviewed metadata」は拳闘士1.01秒と既定剣士0.995秒を同一とする期待値で失敗。`runner_battle_test.dart`の蒼閃は複数敵へのダメージ回数を1とする期待値で失敗（実際119）。今回その戦闘ロジックや期待値は変更していない。
