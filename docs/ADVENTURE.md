# 旧冒険機能の制作記録（2026-10-10）

2026-10-11に旧5ステージ版「以前の冒険の書」を削除した。以下は削除前の制作記録。
現行の冒険画面は `PlayableStageSelectionPage` の九つの世界・全36ステージ。
旧画面への入口、自動戦闘、報酬処理、再開処理は廃止した。
旧保存データの `clearedStages` / `adventureRun` / `lastAdventure` は読み込み時に無視し、次回保存には含めない。
獲得済みポイント・所持品・装備・キャラクター・集中履歴と `clearedPlayableStages` は保持する。
`legacy_adventure_removal_test.dart` で旧データの読み込みと現行冒険・集中・装備変更を検証する。
削除後の関連28テストが通過。現行冒険画面の見出しは小画面・文字1.6倍でも折り返す。

集中はEXPのみを獲得し、冒険はキャラクターの成長後のステータスで攻略する。
集中開始時には従来の戦闘演出を表示し、「タイマーに戻る」「戦いの様子を見る」で切り替えられる。
集中の戦闘演出は冒険の勝敗・進行・報酬から独立しており、集中報酬はEXPのみ。
ホーム「冒険に出発する」または下部メニュー「冒険」から第一章の5ステージへ進む。
集中中は出発できない。進行中の冒険がある場合は結果を確認してから次の集中を開始する。

## 戦闘

主人公1人対、ステージごとに設定した2体の敵。HPを持ち越して順番に戦う。
最後のステージにはゴブリンの王が登場する。推奨レベルは目安であり挑戦条件ではない。
HP、攻撃力、防御力、速度、会心率は既存ProgressionServiceから取得する。
通常ダメージはmax(1, round(攻撃力 - 防御力 × 0.6))、会心は計算前の値を1.6倍。
速度の逆数を攻撃間隔とするイベントシミュレーション。会心は保存したシードから決定する。
敵をすべて倒すと勝利、主人公のHPが0になると敗北。160行動でも決着しない敵戦では撤退する。
1イベント850msで表示。アプリが背景に移動しても開始時刻から表示位置を復元する。
結果はすべてのイベントの表示時間が経過してからGameController経由で保存する。

## 報酬と進行

初回のみ100 / 150 / 200 / 250 / 500ポイントと木の剣 / 旅人の服 / 銀の指輪 / 旅人の服 / 銀の指輪を獲得。
再クリアではEXP・ポイント・アイテムを得ない。全5ステージのポイントは合計1200。
次のステージは直前のステージのクリアで解放する。敗北で所持品やレベルは減らない。
HPは各挑戦で最大値から始まり、敗北後の回復アイテムや待ち時間は不要。

## 保存

PlayerStateにclearedStages、adventureRun、lastAdventureを追加。
schemaVersion 1の既存データには空の進行状態を適用し、集中記録・キャラクター・所持品は保持する。
旧実験版のadventureProgress / stage / pendingBattle / battleHistoryは引き継がない。
adventureRunは開始時ステータス、名前、ステージ、シード、開始時刻を保存する。
戦闘中の装備・仲間変更を禁止する。結果確定・進行解放・報酬付与は1トランザクション。
保存失敗時には進行中の冒険を維持し、結果画面から再試行できる。

## 見た目

ドット絵の主人公は冒険画面に限定する。診断結果・ホーム・キャラクター・集中画面は `JobPortrait` で提供された役職別・男女別の立ち絵を表示する。`role_portrait_ui_test.dart` で冒険以外にドット絵が混入しないことを確認する。

既存の黒地・二重白枠・コマンドUIに王国や森の背景と淡い青緑を合わせる。
主人公はart/animation_materials/character_01/field_pixel_v001の128px待機画像と
field_attack_down_v001の8コマ攻撃シートをassets/images/adventureへコピーしたもの。
敵は既存のslime / goblin移動シート。FilterQuality.noneで表示する。
現在のドット絵は共通の剣士1種類で、職業・男女別のドット絵や専用ボス画像は未収録。
職業・見た目・レベルなどの保存データは保持し、職業別の数値は戦闘に反映する。
