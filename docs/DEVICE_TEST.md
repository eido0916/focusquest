## 実機確認結果（2026-10-04）

- 端末: TB373FU、Android 16。ADBで接続・許可済みを確認。
- 開発用APKのインストール成功。既存データ消去なし。
- `dev.focusquest.focusquest/.MainActivity` のコールド起動成功。
- 初回説明、4問の診断、戦士の作成、チュートリアル完了後のホーム表示を確認。
- タイマーのみのカスタム1分を開始して画面を消し、復帰後に成功、10 EXP、3ポイント、進行度1、今日/累計1分、連続1日が保存されることを確認。
- 使用状況アクセス許可済み・監視ONで「2 Player Games」を対象に設定。集中中に対象アプリを開くと未達成・報酬なしになることを確認。
- 同じ監視設定で対象アプリを開かず画面オフにし、復帰後に成功、10 EXP、3ポイント、進行度1が付与されることを確認。
- 11分として誤開始したセッションを途中中断し、報酬なしになることを確認。
- ゲート以降の短時間検証では、元データを端末内の `player-v1.before-gated-test.json` に保存し、テストデータのみ進行度5・ポイント100へ変更した。製品コードと報酬量は変更していない。
- 自動戦闘でSTAGE 1に勝利し、STAGE 2、EXP +20、ポイント +10、進行度5消費を確認。
- 1回召喚で100ポイント消費、結果・履歴・残高更新を確認。Rレンジャーを編成できることも確認。
- 装備獲得確認の追加召喚でも、その都度テスト用ポイントだけを補充。N木の剣を装備し、レンジャーの攻撃17→20と装備名表示を確認。
- 未確認: 30分実時間完了、戦闘中のタブ移動復帰、報酬確定直前のプロセス終了/端末再起動、集中中の権限取消、再起動後の最終ゲーム状態復元。

## 接続・起動

1. USBデバッグを有効にした実機をPCへ接続し、端末の接続許可を操作する。
2. `adb devices -l` で `device` と表示されることを確認。
3. 開発用APK `output/android/FocusQuest-debug.apk` をインストール。
4. 起動し、説明・4問の診断・職業結果・チュートリアルを完了する。
5. アプリを閉じて起動し、ホームと同じ仲間が復元されることを確認。

## 集中・成長

1. タイマーのみでカスタム1分を開始し、画面を消す。
2. 1分後に戻り、成功・10EXP・3ポイント・進行度1を確認。
3. 再起動や画面の出入りで報酬が増えないことを確認。
4. 別セッションを開始して途中中断し、報酬が増えないことを確認。
5. 30分の集中を完了し、300EXP・100ポイント・進行度30とレベルアップを確認。

## 冒険・召喚・装備

1. 冒険を開始し、キャラクターの前進・ダメージ数字・HP減少・勝敗を確認。
2. 勝利後に次の敵へ自動進行し、残り進行度が減ることを確認。
3. 戦闘中に別タブへ移動して戻り、同じ保存済み敵から再開することを確認。
4. 戦闘結果のEXP・ポイント・アイテムが一度だけ反映されることを確認。
5. 100ポイントで1回召喚し、結果・所持品・履歴・残高を確認。
6. 獲得装備を装備し、ステータスが変わることを確認。
7. 再起動後も仲間・装備・履歴・残高が維持されることを確認。

## Android使用状況

1. 許可しない状態でタイマーのみを利用できることを確認。
2. その他から対象アプリを選択し、Android設定でアクセスを許可、確認スイッチON。
3. 対象アプリを使わず、画面オフのまま1分集中して成功することを確認。
4. 集中中に対象アプリを開いてから戻り、終了時に未達成・報酬なしを確認。
5. 集中中に権限を取り消し、未達成になることとクラッシュしないことを確認。
6. 集中中のアプリプロセス終了・端末再起動後に、同じセッションが復元されることを確認。
