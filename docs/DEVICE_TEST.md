## 接続・起動

1. USBデバッグを有効にした実機をPCへ接続し、端末の接続許可を操作する。
2. `adb devices -l` で `device` と表示されることを確認。
3. 開発用APK `output/android/FocusQuest-debug.apk` をインストール。
4. 起動し、説明・4問の診断・職業結果・チュートリアルを完了する。
5. アプリを閉じて起動し、ホームと同じ仲間が復元されることを確認。

## 集中・成長

1. タイマーのみでカスタム1分を開始し、画面を消す。
2. 1分後に戻り、成功・10EXP・3ポイント・進行度1を確認。
3. 再起動や画面の出入りで報酬が増えないことを確認。
4. 別セッションを開始して途中中断し、報酬が増えないことを確認。
5. 30分の集中を完了し、300EXP・100ポイント・進行度30とレベルアップを確認。

## 冒険・装備

1. 冒険を開始し、キャラクターの前進・ダメージ数字・HP減少・勝敗を確認。
2. 勝利後に次の敵へ自動進行し、残り進行度が減ることを確認。
3. 戦闘中に別タブへ移動して戻り、同じ保存済み敵から再開することを確認。
4. 戦闘結果のEXP・ポイント・アイテムが一度だけ反映されることを確認。
5. 召喚メニューがなく、ホームの冒険ボタンから冒険画面が開くことを確認。
6. 獲得装備を装備し、ステータスが変わることを確認。
7. 再起動後も仲間・装備・履歴・残高が維持されることを確認。

## Androidアプリ警告（2026-10-11）

1. 両権限が未許可の状態で「集中を開始」を押し、使用状況へのアクセスの案内を確認。キャンセルでは集中が始まらないこと。
2. 使用状況を許可して戻り、再び開始。次は「他のアプリの上に表示」の案内を確認。両方許可後に集中を開始し、常駐通知を確認。
3. ブラウザ等を開き、警告と「Focus Questに戻る」「1分だけ使用する」の2ボタンを確認。警告の外側をタップしても背後のアプリを操作できず、キーボードでも入力できないこと。
4. 戻るボタンで進行中のFocus Questに戻り、警告が消えること。
5. 他アプリを開き「1分だけ使用する」を選択。そのアプリは60秒間使用でき、60秒後に再び警告されること。
6. 許可中に別アプリを開くとすぐ警告されること。元のアプリへ切り替えても元の許可期限は延びないこと。
7. ホーム・通知欄・ロック画面・画面オフで警告しないこと。
8. 集中終了時・途中中断時に警告と常駐通知が消えること。以後、他アプリを開いても警告しないこと。
9. 警告や1分の許可を使った後も集中タイマーが進み、終了時にEXPを獲得すること。
10. アプリ再起動で残り時間から監視が再開し、終了済みの集中では再開しないこと。監視サービス再生成後も許可の残り時間を保持すること。
11. 集中中に権限を取り消してもクラッシュしないこと。端末の強制停止・再起動後はFocus Questを開き直して動作を確認。
12. Android 14以降と対象メーカーの端末で同様に確認すること。他アプリのオーバーレイ非表示指定による制限があれば記録。

自動テストでは権限案内・集中開始／終了／中断・保存失敗時の停止・再読込時の監視復元・60秒の境界とアプリ別の許可を検証。上記の実機項目は端末未接続のため未実施。
