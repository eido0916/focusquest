# 2026-10-12 体験改善

- 装備の操作と画面を削除。旧データは読めるがステータスには加算しない。
- 集中中の別タイマー画面を削除。戦闘画面の経過表示を使い、メニューから集中の中断・パーティー画面へ移動する。
- 集中エリアは同じエリアの冒険4ステージをすべてクリアすると解放。未解放でも育成できる初期の訓練場を常設。選んだエリアは集中終了まで固定し、時間経過で別エリアへ移らない。
- レベルアップ時は保存前後の能力を左右に並べ、成長後の値と増分を緑で表示する。
- 初期称号はLv.1。次はLv.10、20、30、40、50、60、70。複数の境界を一度に越えた場合も各獲得称号を順に光の演出で祝う。
- 冒険のステージ一覧に緑のCLEAR表示を追加。保存・再起動後も維持する。
- 同じコードによる本人のパーティー復帰と、戦闘中のコード確認メニューを追加。公開サーバーへの反映が必要。

推奨レベルのシミュレーション方法と結果は `STAGE_BALANCE.md` に記録する。

## 集中ボスの30分サイクル

ボスは今回の集中開始から25分目に出現し、30分目に撃破する。60分なら25分目・55分目に出現する。過去の集中履歴は出現判定に加算しない。30分未満の設定や、30分に満たない最後の端数サイクルにはボスを出さない（45分・59分は最初の1回のみ）。画面を閉じたり通信が切れたりして同じ集中へ戻った場合は、保存された開始時刻から経過時間を復元する。ソロ・パーティーの表示と討伐記録で同じ判定を使う。
