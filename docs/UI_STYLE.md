# 共通UI（2026-10-12）

キャラクター画面を基準に、紺色のパネル、金の装飾、生成り色の文字と紙、SunlitSerifの明朝体、城の中庭背景へ統一しました。

共通部品は `mobile/lib/core/widgets/game_ui.dart` の GamePanel、GameArtwork、GameBackdrop、GameAppBar。キャラクター画面の `character_ui_v002` 素材を読み込み、画面幅に応じて装飾枠の角の大きさを保持します。QuestCard、QuestActionButton、SunlitFrameもこの共通部品を使用します。

ホーム、集中選択と集中中、冒険一覧とステージ詳細、パーティー、設定、職業診断、冒険者証のヘッダー、開発者用選択、戦闘のステータス枠と結果表示へ適用しています。透過が必要なプレイヤー枠は透過素材を維持します。ドット絵の原画・攻撃素材・命中判定・育成・保存処理にはUI変更を加えていません。

確認画像：`output/home/390-home.png`、`mobile/build/unified-ui/focus-390.png`、`mobile/build/unified-ui/settings-390.png`。スマホ、横画面、文字拡大のレイアウトと、診断・集中・ステージ挑戦・パーティーの操作を既存テストで確認しています。
## 装飾枠の重なり修正

GamePanelは装飾の幅に応じた安全な内側余白を確保し、下端の飾り全体を固定領域として描画します。縦長パネルでも中央の飾りが本文へ伸びません。下部ナビゲーションは選択中もアイコンと文字を中央へ揃え、文字拡大時に必要な高さを確保します。GameAppBarの戻る・保存操作は枠の左右端から離して配置します。`frame_spacing_test.dart` で画面幅320・643・1920pxの中央揃えと内側余白を検証しています。

集中時間設定は画面の向きに応じて切り替えます。縦画面は従来の縦長比率（横幅基準、最低高さは横幅の1.5倍）、横画面はステージ・パーティー・時間設定・開始を近接配置した比率を使い、利用可能な高さに収めます。
