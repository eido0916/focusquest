# Focus Quest プレイアブルステージ・デモ

既存の集中画面と独立したブラウザ用デモ。character_01の剣士が左、敵が右に配置されます。

1. 草原を走行 → スライム（HP112）。
2. 敵を倒すと自動走行 → ゴブリン（HP168）。
3. 再び自動走行 → ボスのドラキュラ（HP280）を倒してクリア。

タップ／クリックで「攻撃」（28ダメージ）、「スキル」（112ダメージ）。通常攻撃を3回命中させるとスキルが解放され、発動時にゲージを消費します。ゲージはフェーズをまたいで保持します。キーボードはA・S、Pで一時停止。敵も定期的に攻撃し、HPが0になると再挑戦できます。フェーズ突破時はHPが16回復します。

## ローカル起動

リポジトリルートで `python -m http.server 8765 --bind 127.0.0.1` を起動して、http://127.0.0.1:8765/playable-demo/ を開きます。依存パッケージのインストールやビルドは不要。JSON読込みのため、file://ではなくHTTPで開いてください。

`node --test playable-demo/engine.test.mjs` で状態遷移、スキル解放、入力重複、全フェーズのクリア、敗北、停止・リセットを確認できます。

素材の検証は `python scripts/verify-playable-demo.py`（Pillowが必要）。100原画・13動作・328表示tickのハッシュと再生情報を確認しています。ブラウザ上でも3フェーズを通常攻撃12回・スキル3回でクリアし、390×844px表示で横のはみ出しがないことを確認済み。確認画像は preview-desktop.jpg と preview-mobile.jpg。

## 原画再生

素材はv010から必要な100原画PNGのみをバイト列を変えずにコピーしています。24fpsのJSON timelineが指定する原画を保持します。走行・待機はループ、攻撃・スキル・撃破は一度だけ再生します。キャラクターの回転・伸縮・モーフィング・クロスフェード・中間画像はありません。表示は64px論理格子の整数倍・最近傍。走行、攻撃時の接近、撃破ノックバックはワールド座標として扱います。

原画は assets/manifest.json のSHA-256で出典を確認できます。再パッケージは `python scripts/package-playable-demo.py`。描画サイズは全動作共通です。今後の作画で待機基準へ揃える方針を維持し、既存v001待機とv005の姿勢・頭身の差は素材通りに残しています。

このデモはFlutterアプリへの組込み、集中実績とのレベル連携、永続保存を含みません。ゲームバランスはデモ用の仮値です。
