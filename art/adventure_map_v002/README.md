# 冒険の書・配置修正 v002

2026-10-29。最初のデザイン案とユーザー添付の実画面を比較し、画像・数字・装飾の位置を修正。

## 修正

- ステージの円形枠と道の接続点を同じ941×750座標に統一。固定の9px余白によって枠の中心が道から下にずれる問題を解消。
- 数字は同梱NotoSerifJPの実際のインク範囲を測り、枠の光学的な中心に配置。1桁・2桁、通常・ロック中で文字の余白に引っ張られない。鍵は数字と重ならない上部へ配置。
- 大きい画面は470pxの基準レイアウトから比率を揃えて拡大。文字・ボタン・アイコンだけが小さく残る問題と、金のボタンが横に潰れる問題を解消。小画面と文字拡大時の縦並びは維持。
- 見出しの左右の占有幅を揃え、タイトルを枠の中央へ配置。
- サムネイルの縦横比を最初の案に合わせて1.65へ変更し、枠の内側余白とクリップを確保。画像が金の枠に重ならないようにした。
- 王冠と旗のサイズ・上部の間隔を揃え、状態ラベルの中央もステージの枠に揃えた。
- 霧の格子模様を、個別SVGから生成する滑らかな透過オーバーレイ2枚に変更。元のv001素材は保存。
- 見出し背面の空の色を調整し、地図の城が二重に目立つ背景の継ぎ目を緩和。

## 検証方法

数字は全36Stage×通常／ロックの72通りを実際に描画し、RGBA画素の明るい文字部分を抽出して中心位置を検査。中心の許容差は1.2px。文字のメトリクスは [number-ink-metrics.json](number-ink-metrics.json)。フォントを変更する場合は再計測する。

レイアウト検査は、道の接続点と枠の中心、ラベルの中央、見出しの中央、サムネイルの枠内余白、ボタンの縦横比を比較。760×1360の大画面・集中中の表示、470×836、320px幅・文字倍率1.6、横画面、9章の表示を確認。
