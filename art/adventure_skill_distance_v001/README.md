# 冒険スキルの距離と命中表示の修正

剣士の蓄力斬撃は、主人公の前に固定されたv002斬撃原画を表示しながら、非表示の追尾飛び道具で遠方の敵にダメージを与えていた。冒険の戦闘モデルと描画を修正。

- 剣士は斬撃の実描画幅を基準に間合いを取り、原画の放出イベントで一度だけ命中。鎌使い・バーサーカーの有限範囲の原画も同じ方式。
- 剣士の刃の接触位置はエフェクト原本のx約350px（128pxキャラ単位で2.75）。通常敵と3倍ボスの手前側の位置を加味し、画面の表示倍率からワールド座標の間合いへ換算する。
- その他の近接職も、命中時に前方の攻撃範囲内であることを確認する。
- 遠距離スキルは内部の飛び道具を実際に描画し、既存の着弾判定と表示位置を一致させる。詠唱動作の終了後も飛行中の弾を描画。
- スキル発動中に被弾しても、命中動作を被弾原画で隠さない。
- 威力・チャージ消費・元の原画PNG・補間なしの描画は維持。接近はゲーム内ワールド座標のみで行う。

`previews/` はダメージが入った瞬間のFlutter実描画。男女×通常敵／ボス×390・960・1280px幅の12枚。

検証コード: `mobile/test/playable_stage_skill_distance_test.dart`、`playable_stage_skill_projectile_visual_test.dart`。放出前のHP保持、原画の放出コマとの同期、範囲内の接触、二重ダメージ防止、帰還、飛び道具の実座標での可視性を確認する。

既存の接近・遠距離・効果表示・戦闘・音声テストも確認。ログは本フォルダに保存。
