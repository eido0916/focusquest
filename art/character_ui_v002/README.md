# キャラクター画面 v002

添付「冒険者証付きキャラクター画面.png」を参考に、城の背景・立ち絵・紺と金の名前帯・羊皮紙のステータス枠・装備欄を個別素材で組み立てています。

- `materials/`: 新作の装飾4点、背景・装備アイコン・称号一覧枠5点、個別の操作・能力アイコン10点。合計19素材。
- `originals/`: built-in imagegenで生成した元画像。元の制作素材は保持。
- `role_logos/`: 添付ZIPの16点を元ファイルと同じバイト列で保存。対応表とSHA-256は`manifest.json`。
- `prompts.md`: 生成に使用した指示。

操作・能力アイコンはアプリで使用しているMaterialIconsの同じ図柄を個別透過PNGへ書き出しました。ライセンスは`materialicons_license.txt`に同梱しています。

画面の日本語、名前、数値、EXP、装備、ボタンはFlutterの実際のウィジェットです。背景画像に文字を焼き込んでいません。職業ごとの立ち絵と背景には既存素材を使用しています。

称号一覧は既存のCertificateCatalogにある職業別8称号を使用し、従来どおりLv.1〜8で1段階ずつ解放します。選択した称号をキャラクターごとに保存し、冒険者証にも反映します。旧セーブは最高解放称号を自動表示します。

職業ロゴはキャラクター画面、集中の選択画面、タイマー画面、単独戦闘HUD、パーティ戦闘の名前横で使用します。
