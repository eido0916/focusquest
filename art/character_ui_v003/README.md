# 装備なしキャラクター画面 v003

添付「蒼き城の狂戦士キャラクター画面.png」を基準にしたFlutterの実画面。
人物、職業紋章、名前、称号、レベル、EXP、能力値は実際のプレイヤーデータに連動します。
冒険者情報は「称号変更」「冒険者証を見る」の2項目。現在の称号の補足文字は表示しません。

## 素材

- `materials/`：個別PNG18点。背景、見出し、人物情報枠、EXP枠、羊皮紙枠、能力値枠、冒険者情報枠、ボタン枠、各アイコン。
- `originals/`：組み込み前のImageGen生成原本3点。既存素材は上書きしていません。
- `role_logos/`：既存の提供済み職業紋章。
- `portraits/`：プレビューに使用する提供済み狂戦士の人物素材。
- `previews/`：Flutterから出力した画面画像。
- `manifest.json`：PNG寸法とSHA256。
- `prompts.md`：built-in image_genで使用したプロンプト。

城の背景、人物、紋章、従来の装飾枠は既存の確定素材を再利用しました。
冒険者情報枠・能力値枠・EXP枠は個別に新規生成。
剣とブーツのアイコンは透過PNGとして個別制作しました。
文字と数値はPNGへ焼き込まず、操作可能なFlutterウィジェットとして描画します。

## 装備廃止

装備・所持アイテムの操作入口を削除。装備APIは変更を拒否し、能力値加算を停止しました。
旧セーブの装備・所持品データは読み込み互換性のため維持され、能力値に影響しません。
プレイヤー・敵のドット絵アニメーションは変更していません。

制作スクリプト：`scripts/package-character-no-equipment.ps1`。
