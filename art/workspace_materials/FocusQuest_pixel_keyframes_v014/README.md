# ボス9体の高精細原画 v014

既存ボスを細部から描き直した透過ドット絵です。PNGは128×128pxから384×384px、論理格子は64×64から192×192へ変更。ゲーム内の大きさは維持します。v013以前の原画は保存しています。

対象はゴブリンキング、サイクロプス、騎乗デュラハン、火竜、リッチ、ミノタウロス、石のゴーレム、ケルベロス、魔王。移動・攻撃・被弾・撃破の36動作、217原画を収録しています。

制作にはbuilt-in image_genを使用しました。既存原画の外見・左向き・姿勢の並びを参照し、顔・牙・角・鎧や武器の彫り・毛並み・鱗・石の割れ目・炎を細かいドットで描き直すプロンプトを使用。各ボスの`source/<boss>/production.json`に制作条件と参照先を記録しています。デュラハンは動作別4枚、その他は全動作1枚の生成アトラスから原画を切り出しています。魔王の攻撃は隣接コマとの接触を避けるため、専用2×2アトラスを再生成し、構えの体高に合わせた固定倍率で登録しました。

切り出し時のみ共通倍率でポイントサンプリングして192pxの論理格子に登録し、2倍の最近傍で384pxに書き出しています。動作ごとの拡大率変更、パーツ変形、回転、補間、モーフィング、クロスフェードは行いません。

各動作フォルダには`keyframes/`、`frames_24fps/`、保持時間・原画番号・ワールド座標イベントを含む`animation.json`、`sprite_sheet.png`、`preview/animation.gif`があります。全連番のRGBAが対応する原画と完全一致することをSHA-256で検証しました。確認用の`index.html`と`verification.json`も収録しています。

足元アンカーとノックバックなどのワールド座標は128px基準のままです。Flutterは画像全体を描画し、HPバーの位置のみ画像解像度を換算します。再生タイミング、命中判定、ボスの表示サイズは既存どおりです。
