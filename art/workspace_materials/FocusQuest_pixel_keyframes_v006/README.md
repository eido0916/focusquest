# FocusQuest原画アニメーション v006

character_06アサシンの走行・短剣突き・蓄力クリティカルを追加しました。新作28原画の詳細は `ASSASSIN_V006.md`、検証は `assassin_verification.json` を参照してください。現行素材集はプレイヤー6体・敵3体、計30動作です。既存キャラクターの素材はv005と同じです。以下はcharacter_01についてのv005制作内容です。

イラスト1.pngの剣士をもとに、character_01の走行8原画・停止して縦斬り8原画・構えと蓄力から斬撃を放つ12原画を新規制作しました。待機はv001の原画を保持しています。character_02〜05と敵3体はv004と同じ素材です。

走行は8原画を各2表示tick保持する0.667秒ループです。左右接地・沈み込み・通過・浮遊を描き分けています。縦斬りは1秒、頭上で構えた剣を前方の足元まで振り下ろし、戻します。スキルは1.75秒、剣にエネルギーを集め、振り下ろし後に右へ青い斬撃を放ちます。ゲーム内では攻撃・スキルを1回再生、プレビューは繰り返します。

確定した原画PNGをそのまま切り替えます。変形・補間はありません。原画28コマは内蔵画像生成ツールで制作し、v001の待機を基準とした立ち姿の高さ43論理px、64×64論理格子、背景二値透過、2倍の128×128pxで書き出しました。制作時の正規化は動作内で一定の倍率を使い、再生中の変形はありません。走行浮遊の足元はy=108〜112px、接地および停止動作はy=114pxです。全3動作は共通40色パレットです。

`keyframes/` は個別原画、`frames_24fps/` は完全なコピー連番、`animation.json` は原画番号・保持tick・イベント・座標、`sprite_sheet.png` は原画一覧です。GIFと透過APNGは `preview/` にあります。GIFの時間は10ms単位に丸められるため、実装はJSONか24fps連番を使用してください。根元の移動はゲーム側で扱い、走行画像はその場で足を動かします。飛び道具の当たり判定も別途制御します。縦斬りの攻撃はtick13、スキルの斬りはtick30、斬撃放出はtick31です。

走行→攻撃・走行→スキルの連結版も新原画に更新しました。2周走行→停止構え4tick→攻撃という構成です。編集元の生成アトラス・生成指示・原画・寸法記録は `source/hero_swordsman_v005/`、書き出しコードは `source/prepare_swordsman.py` にあります。

v001〜v004と元素材を保持しています。v003のSTYLE_V003.md、source/hero_style_v003、restore_verification.jsonなどの旧記録は履歴です。現行の検証結果はverification.jsonとswordsman_verification.jsonを参照してください。
