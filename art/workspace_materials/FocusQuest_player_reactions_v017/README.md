# 男女16職業の被弾・膝をつく敗北 v017

現在のゲーム用のキャラクター原画を外見・配色・頭身の基準に、built-in image_genで姿勢を描き起こしました。男女16職業・32体に被弾4原画と敗北4原画、計64動作・256原画を追加した補完版です。以前の走行・攻撃・スキル・待機・敵素材は保持します。

- 128×128px透過PNG、64×64論理格子を2倍の最近傍で出力。
- 全コマ右向き。被弾は構え→のけぞり→回復、12tick・0.5秒。
- 敗北は疲弊→膝を曲げる→片膝を地面につく→両膝をついて頭を下げる、30tick・1.25秒。最後の原画は消さず保持します。
- 天使・悪魔は翼を収めて着地します。武器・衣装・髪などの特徴を保持。
- 体高は各キャラクターの参照原画へ合わせ、全動作を1つの固定倍率で登録。膝をつくことで姿勢だけが低くなります。
- 被弾の後退は最大6px左、敗北は最大4px左のワールド座標イベント。原画内のパーツ変形・回転・補間・クロスフェードは使用しません。

各キャラクターのフォルダに`keyframes/`、`frames_24fps/`、保持時間・原画番号・座標イベントの`animation.json`、`sprite_sheet.png`、`preview/animation.gif`を収録しています。24fps連番のRGBAと対応原画の完全一致は`verification.json`で検証します。GIFは確認用に最後の姿勢を長めに保持してループし、ゲームは敗北を一度だけ再生してそのまま保持します。

`source/<character>/`には生成アトラス、参照PNG、使用した正確なプロンプト、固定倍率・体高・足元位置の登録JSONがあります。元の生成アトラスを保存し、原画抽出時は連結した描画全体を取り出して足先や武器を切らないようにしています。独立した小さな出力ノイズを除き、二値アルファとポイントサンプリングで原画を登録します。

Flutterは各職業の`hero_hurt`と`hero_defeat`を読み込み、命中時に被弾を再生します。被弾表示でダメージ・命中率・攻撃間隔などの戦闘計算は変えません。HPゼロでは戦闘を止め、敗北原画のみを1.25秒再生して結果画面を表示。再挑戦時は反応・敗北の再生状態をリセットします。

1,344枚の24fps連番のRGBA一致、64px論理格子の正確な2倍出力、既存1,215枚の保持を検証しています。原画一覧とアニメーションの確認は`index.html`、32体の一括確認は`reactions-preview.gif`と`kneeling-preview.png`から行えます。プロンプト一式と入力一覧は`generation-inputs.json`、再登録は`scripts/package-player-reactions.cjs`、検証は`scripts/verify-player-reactions.cjs`を使用します。
