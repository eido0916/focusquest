# FocusQuest：ドット絵原画アニメーション

ユーザー指定により、プレイヤー・敵のアニメーションを「原画コマをそのまま切り替える」方式に統一しました。変形・回転・伸縮・モーフィング・中間フレーム補間・クロスフェードは使いません。今後の制作方針はワークスペースの `AGENTS.md` にも記録しています。

対象は制作済みのプレイヤー01〜05とスライム・ゴブリン・ドラキュラです。プレイヤー06〜16はアニメーション未制作なので含みません。以前の非ドット絵・パーツ変形による試作は元のフォルダに保存し、この現行素材集には含めていません。

## 再生方法

各動作の `keyframes/` が128×128pxの透過原画です。`animation.json` の `timeline` に記録された原画を毎秒24回のタイミングで選びます。保持中は同じ画像を再表示します。`frames_24fps/` は原画をそのままコピーした連番であり、中間画像ではありません。全連番のRGBA画素が対応原画と完全一致することを検証しています。

移動は `root_offset_px` を基準位置に加えます。絶対オフセットなので毎フレーム累積加算しないでください。敵の左移動と忍者の瞬間移動も原画を変更せず座標データで表します。ゲーム側の移動処理と画像の補間は別です。画像は原画の切り替えのみを使います。テクスチャはポイントサンプリング、拡大は整数倍の最近傍法を推奨します。

`sprite_sheet.png` は原画の並べ置き、`preview/animation.gif` は配置も反映した確認用、`preview/animation.png` は配置前の128px透過APNGです。GIFの時間は10ms単位に丸めているため、正確な再生時間はJSONとPNG連番を使用してください。確認用プレビューはループしますが、攻撃・スキルはゲームで1回再生を想定しています。

## 元素材と変更点

既存のドット絵原画は描き直したり再減色したりせずに収録しています。主人公01の待機のみ、まばたきと小さな呼吸を描いたドット絵原画として新規制作しました。元の高解像度立ち絵と過去の編集元は `FocusQuest_character_preproduction_v01/` に保持しています。

主人公01の「走行→攻撃」「走行→スキル」は単体原画を直接連結する構成に変更しました。以前の比較用まとめで行っていたサイズ合わせは行わないため、動作の切り替え時には元原画の表示サイズ差が残ります。サイズを揃えるための動的変形も使用しません。

手裏剣、刀や剣のエネルギー、煙などの描写は各原画に含まれます。ゲームの飛び道具や当たり判定は別途制御してください。既存の攻撃タイミングは `events` と元仕様の `source/original_animation.json` を参照できます。

`catalog.json` にキャラクター・動作・原画数・連番数を一覧化しています。`verification.json` は画素一致、透過、寸法、ZIP内の収録素材の確認結果です。`source/build_catalog.py` は元の制作フォルダから現行素材をまとめる編集可能なPythonソースです。元フォルダとPillow・NumPyが必要です。
