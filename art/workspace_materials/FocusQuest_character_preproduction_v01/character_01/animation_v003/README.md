# キャラクター01：参考動画を反映した走行 v003

前版v002を残し、イラスト版とドット絵版の走行を修正。元画像1.pngおよび既存の待機素材は変更していない。

## 参考映像と反映内容

- [走りアニメーションの作り方。How to create a run animation.](https://www.youtube.com/watch?v=lK6iiZBxJuk)：ブラウザー再生で1:04の通過、1:20の蹴り上げ、2:07の空中、2:30の接地、2:47の沈み込みを確認。接地後の体重による膝の屈曲、後ろの踵の回収、膝の前方への送り、蹴り出しと空中時の腰の高さ、脚より先に交差する腕を参考にした。
- [【ポケモンZA】走るモーションが最高に素敵な理由](https://www.youtube.com/shorts/3Bzsj4HMpI8)：ブラウザーで再生中の横向きの走行姿勢を確認。曲げた肘、後方で曲がる膝、前後に離れた脚、衣服と髪の追従するシルエットを参考にした。複数人物の身体や衣装をキャラクター01へ移植していない。

映像の骨格データを取得したものではない。以下の位相・寸法・角度は、画像内の可動範囲と剣の保持に合わせて設定した制作上の値。2本目をフレーム単位で全編解析したものではない。

## 前版からの変更

足首の対称的な持ち上げを、後ろの踵を早く回収してから前へ送る非対称の軌道へ変更。接地は片脚の周期の38%、左右は半周期ずれる。接地足首は256基準でx154→104、y212。蹴り出し後、位相0.52で(103,165)、0.64で(123,155)、0.80で(153,177)を通り、次の接地へ戻る。各区間は位置と速度を指定した3次Hermite補間で接続。腿41.5px、すね40.5pxの固定長IKで膝を決める。

腰は接地後にy139→144へ沈み、空中付近でy135へ上がる。上体は腰から首へ右に18px進む前傾とした。腕の周期を脚から0.08周期先行させ、肘は95°曲げる。剣側の上腕の振幅は25°、空いた側は38°。握り点は手の掌と剣の共通点で、剣先は握り点からの相対位置で決まる。

足首の接地位置と、ブーツの輪郭の接地は区別する。ブーツは剛体パーツのため、踵からつま先へ体重を移す靴底の変形はまだ作っていない。接地中の画面内後退速度は50/0.38≒131.58基準px/秒。ゲーム内の右方向移動をこの速度に合わせれば接地足首の世界座標は静止する。ゲーム側の速度が異なる場合は再生速度を調整する。

## 納品内容

- `comparison.gif`：イラスト版／ドット絵版を同じ位相で並べた確認用アニメーション。
- 各版 `preview/run.gif`：背景付き確認用、`run.webp`：透過WebP、`run.png`：透過APNG。
- 各版 `preview/all_24_poses.jpg`：全24姿勢の比較。
- 各版 `runtime/run/`：256×256透過PNG24枚、24fps、1秒、ループ。`runtime/animations.json`に順番・時間・足元位置。
- 各版 `production_frames/run/`：1024×1024の完成連番。
- 各版 `parts/`：20枚の個別透過PNG。v002の元パーツを維持。
- 各版 `source/rig.json`：画像内の関節端2点、初期配置行列、全フレームの関節位置、描画順。
- 各版 `source/frame_transforms.json`：24フレーム分の各パーツの配置行列。
- 各版 `source/frame00_layers.svg`：編集可能な画像層配置。
- 共通 `source/renderer.py`：動作・パーツ配置・再書出し元。Python3＋Pillow＋NumPy。
- `qa.json`、`verification.json`：書出しと数値検証結果。

イラスト版は1024で描画して256へ縮小。ドット絵版は論理128×128へNEAREST描画し、全周期共通32色枠（透明を含む）と0/255アルファで整理。実装256は整数2倍、制作1024は整数8倍。パーツの輪郭は回転時にドット単位で変化する。

GIFは10ms単位のため40/50msを配分し、1秒周期を維持。WebP/APNGは41/42msを配分。厳密な24fpsの正本はPNG連番とF/24秒のメタデータ。

## 検証と残る範囲

1001時点で脚のIK到達範囲、軌道の接続速度、骨端座標の一致、全24枚の関節中心近傍のアルファ被覆、透過・寸法・安全余白、ドット絵の2×2ブロック一致と色数を確認。全姿勢比較で見た目も確認する。

関節中心の被覆検査は輪郭線や布の自然さを保証するものではない。イラストの袖口やブーツの折り返しの線は既存の絵に含まれ、曲げた時の線の連続性には追加の描き替え余地がある。髪は頭パーツと一体、マントと裾は面の回転で表現。Android実機とゲーム内移動速度の同期は未検証。今回の納品は参考動画を反映した走行試作2種類で、残り15体の本制作には進めていない。
