# キャラクター01：立ち止まって剣を振り下ろす

同じミニキャラの右向き・その場での単発攻撃。足元を揃え、構え→予備動作→振りかぶり→振り下ろし→打ち込み→振り終わり→回復→構えへ戻す。走行および待機の既存ファイルは変更していない。

## 納品

- frames/character_01_attack_down_00.png〜07.png：128×128の透過PNG8枚。07は00と完全に同じ帰還姿勢で、異なる姿勢は7種類。
- frames_24fps/：各姿勢を保持した24fps用24枚、1秒。24種類の異なる絵ではない。
- character_01_attack_down_sheet_128.png：128×128セルの4列×2行透過シート。
- preview/all_8_frames.png：番号入り一覧。
- preview/attack_down.gif：背景付き繰り返し確認用。
- preview/attack_down.webp、attack_down.png：透過WebP/APNG。
- animation.json：順番・保持フレーム数・単発再生指定・時間・寸法。
- source/generated_attack_sheet.png：内蔵image_genで生成した原稿。source/prompt.txtに正確な生成指示。
- source/export_frames.py：セル分割、足元の位置合わせ、共通色の整理、連番とプレビューの書出し元。
- verification.json：サイズ、アルファ、ドット、見切れ、姿勢の相違、開始・終了一致の数値確認。

論理64×64から整数2倍、全コマ共通24色以内、透明0/255。元のミニキャラと右向き走行一覧を参照し、新しい剣の振り下ろし姿勢を生成。頭や服の細部の全ピクセルが既存画像と同一になるものではない。

## 時間

24fpsでの各姿勢の保持フレーム数は4,3,4,1,1,4,3,4。構えと振りかぶりを見せた後、振り下ろし・打ち込みを短くし、振り終わりと復帰を見せる。全体1秒。ゲームでは単発再生、プレビューは確認のため繰り返す。GIFは10ms、WebP/APNGは1msに丸めて周期1000msを維持。

この素材は立ち止まった状態からの攻撃。走行からの減速遷移や敵との衝突判定、ダメージ発生タイミングはアプリ側の制御事項で、完成フレームに移動量を含めない。今回、独立可動パーツや斬撃エフェクトは作成していない。
