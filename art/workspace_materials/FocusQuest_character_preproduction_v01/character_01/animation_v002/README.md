# キャラクター01：走行修正＋ドット絵走行 v002

2026-10-09。前版v001は残し、別フォルダに2種類の走行を制作。

## 今回の修正

前版は各パーツの外接矩形を基準に置いていたため、絵の中の関節の端と親子回転の基点が一致せず、肩・肘・膝・足首に段差が出ていた。腿とすねをそれぞれ周期角で動かしていたため、足の接地や振り戻しにも一貫性がなかった。

今回は、画像内の上腕の肩・肘、前腕の肘・手首、腿の股・膝、すねの膝・足首を2点で指定し、それらを骨格の同一関節へ写す配置に変更した。接合点の前後には絵の重なりを残す。斜めに描かれたパーツも細く潰れないよう、腕・脚の幅を骨に直交する方向で測って配置する。剣の握り中心は手の掌と共通。

脚は足首の軌道から、固定の腿長41.5px／すね長40.5px（256基準）で膝を求める2ボーンIKへ変更。膝は右へ曲がり、足を後ろへ回収してから前へ運ぶ。左右の脚は半周期ずらす。接地区間38%、振り戻し62%、双方の接地がない短い空中区間あり。片足1周期の足首は、接地でx150→102、y212一定。振り戻しでは足首を38px持ち上げる。水平軌道は3次Hermite曲線で、蹴り出しと次の着地の速度を接地区間へ接続する。

体重移動、上体の前傾、空いた腕の振り、剣腕の小さな振り、マントと裾の遅れを同じ周期へ合わせた。キャラクター全体の右への移動は焼き込まない。その場走りのため足は画像内で後ろへ動く。接地中の想定進行速度は48/0.38≒126.32基準px/秒で、システム側の移動を加えた世界座標では接地足の横位置が一定になる設計。ゲーム側の速度が異なる場合は再生速度を調整する。

## 2種類

### illustration：現在の絵柄の修正版

v001の20パーツ画像を再利用。新しい人物へ描き直さず、配置・骨格・可動方向・歩容を修正。1024pxで再合成し、256pxへLANCZOSで縮小。PNGパーツとPNG連番、透過WebP/APNG、確認GIFを格納。

### pixel：ドット絵での走行

原画1.pngを参照し、金髪・青い目・白シャツ・青いマント・革帯・茶ブーツを保った20パーツのドット絵素材を内蔵image_genで新規生成。上と同じ骨格・接地タイミングで走行を制作。

論理128×128グリッドでNEAREST描画、全周期共通32色枠（透明を含む）へ整理、アルファを0/255に固定。実装256版は整数2倍、制作1024版は整数8倍で書出し。パーツの移動・回転もこのグリッドへ描画されるので、滑らかなイラストとは違いドット位置が段階的に変わる。最終PNGが等間隔ドットであることを検査する。

## 再生・納品

- 各版preview/run.gif：背景付き確認用。
- 各版preview/run.webp：透過アニメーション。
- 各版preview/run.png：透過APNG。
- 各版runtime/run/：256×256透過PNG24枚、24fps、1秒、ループ。
- 各版runtime/animations.json：時間・寸法・足元・ファイル順。
- 各版production_frames/run/：1024版24枚。pixelは128の整数拡大。
- 各版parts/：20枚の個別透過PNG。
- 各版source/rig.json：画像内の骨端2点、frame00の配置行列、全フレームの関節位置、描画順。
- 各版source/frame_transforms.json：全24フレーム・20パーツの配置行列。元パーツのピクセルから256基準キャンバスへの変換を再現できる。
- 各版source/frame00_layers.svg：frame00の編集可能な画像層配置。
- source/renderer.py：共通の走行と再書出し元。Python3＋Pillow＋NumPy。
- source/pixel_parts_atlas.png：ドット絵の生成元。
- source/imagegen_prompts.json：内蔵image_genの正確な生成指示。
- comparison.gif：同じ位相・同じ倍率で2種類を並べた確認。
- pose_comparison.jpg、joint_guide.jpg：4姿勢比較と関節基準の図。
- qa.json、verification.json：数値検査結果。
- source/verify.py：連番、関節のアルファ被覆、ドットの等間隔ブロック、軌道の速度接続を再検査するスクリプト。

アプリ登録用はruntimeの完成フレーム。素材担当用のparts/sourceを完成フレームと混同しない。元の1.png、v001の立ち絵・待機は変更していない。今回の追加対象は走行2種類。

GIFの時間分解能は10msのため40/50msを配分し、1周期1000msとした。WebP/APNGは41/42ms配分。厳密な24fpsの正本はPNG連番とF/24秒のメタデータ。終点t=1は次周期F0なので重複フレームを追加していない。

## 検査の意味

骨端を共有関節へ写した座標誤差、接地中の足首yの誤差、周期の関節一致、画像枚数・寸法・RGBA・安全余白、ドット絵の色数と2×2ブロック一致を検査。1001時点の逆運動学で全足首目標が脚の長さの範囲内にあることも確認した。

接合座標が一致することと、すべての輪郭線・布の変形が完全に自然であることは別。既存のイラスト素材には袖端や折り返しの線が残り、マントは面の回転で表現している。今回の走行全24姿勢を確認用に納品するが、Android実機・ゲーム内移動速度との同期・全動作の品質合格は未実施。原画との同一人物認識と2種類の動きはユーザー評価対象。
