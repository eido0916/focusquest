# キャラクター05：忍者アニメーション

参照元は `../reference/5.png`。黒髪、顔を隠さない紺色の長いマフラー、黒い服、紺の帯、腕と脚の巻き布、茶色の草履を残した128×128pxのミニキャラドット絵です。右向き、背景透過、24fps。

|動作|原画|24fps連番|時間|ゲームでの再生|
|---|---:|---:|---:|---|
|run：走行|8枚|16枚|約0.667秒|ループ|
|shuriken：停止して手裏剣を投げる|8枚|36枚|1.5秒|1回|
|teleport_stab：指の構え・瞬間移動・短刀突き|12枚|48枚|2秒|1回|

走行は左右の脚で接地、沈み込み、蹴り出し、空中姿勢を描き分け、マフラーを後ろへ流しています。画像はその場で走る素材なので、ゲーム側で右に移動してください。攻撃時は走行を止めます。

瞬間移動は指を胸の前で構え、消失と煙を挟み、前方へ現れて右手の短刀で突きます。消失中の空白フレームは意図したものです。128pxの原画はキャラクターを基準位置で保持しています。ゲーム側ではJSONの `teleport_forward` イベントで座標を右へ64px移動します。`root_motion_keyframes_px` は絶対オフセットです。毎フレーム加算しないでください。実際の移動距離はゲーム側で変更できます。GIFプレビューと比較画像にはこの移動を反映しています。透過APNGは配置前の素材プレビューです。

## 使用方法

- `frames/`：原画の個別透過PNG。
- `frames_24fps/`：保持時間を展開したPNG連番。番号順に24fpsで再生します。
- `character_05_*_sheet.png`：128px単位のスプライトシート。左から右、上から下の順。
- `animation.json`：保持時間、原画と連番の対応、配置変換、攻撃と瞬間移動のタイミング候補。
- `preview/animation.gif`：配置と動作の確認用。時間は10ms単位に丸めています。
- `preview/animation.png`：128pxの透過APNG。
- `preview/keyframes.png`：原画一覧。
- `comparison.gif`：3動作の比較。

原点は左上、Xは右、Yは下。キャラクターの足元基準は `(60,114)`。最終画像は64×64の論理ドットを最近傍法で2倍にした2px格子です。プレビューは比較のためループしますが、攻撃はゲームでは1回再生してください。手裏剣の軌道と瞬間移動の煙は画像に合成しています。実際の飛び道具や当たり判定はゲーム側で制御してください。

## 編集元

組み込みimagegenで生成しました。各 `source/generated_atlas.png` は高解像度原画、`source/prompt.txt` は生成指示です。共通 `source/export.py` は分割、配置、減色、PNG/GIF/APNG/JSON/ZIP書き出しの編集可能なPythonソースです。PillowとNumPyが必要です。

納品はフレームアニメーション素材です。ボーンや関節ごとの独立パーツは含みません。小さい表示に合わせて装飾を省略しており、生成原画間には顔や服の小さな描画差があります。元のプロフィールイラストは上書きしていません。寸法、透過、ドット格子、余白、再生時間の確認結果は `verification.json` に記録しています。
