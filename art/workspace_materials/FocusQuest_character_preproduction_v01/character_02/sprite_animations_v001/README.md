# キャラクター02：拳闘士アニメーション v001

参照画像 `../reference/2.png` の赤髪、茶色のフードと赤い裏地、白い胴着、赤い帯、拳の包帯、茶色の靴を、右向きのミニキャラに整理した素材です。元のイラストは変更していません。

|動作|原画PNG数|24fpsの表示フレーム数|時間|ゲームでの再生|
|---|---:|---:|---:|---|
|run：走る|6|12|0.50秒|ループ|
|punch_combo：停止して3連続パンチ|12|30|1.25秒|1回|
|spin_kick：足に蓄力して回転蹴り|12|30|1.25秒|1回|

全素材は128×128pxの透過PNGです。64×64の論理ドットを最近傍法で2倍にしており、輪郭に半透明のぼかしはありません。小さい表示向けに服の細かい装飾を省略しています。

## 使用方法

- 各動作の `frames/` は原画の個別PNGです。停止動作の最終原画は開始姿勢と同じ画像にしてあります。
- `frames_24fps/` は保持時間を展開したPNG連番です。番号順に毎秒24枚で再生してください。同じ原画の保持フレームを含みます。
- `character_02_*_sheet.png` は原画のスプライトシートです。128px単位で左から右、上から下の順に読みます。
- `animation.json` に原画の保持時間、24fps連番と原画の対応、攻撃タイミング、配置変換を記録しています。原点は左上、Xは右、Yは下です。基準の足元は `(64,114)`、全動作のキャンバスサイズは同じです。
- `preview/animation.gif` は2倍表示の確認用です。GIFでは時間を10ms単位に丸めています。`preview/animation.png` は128pxの透過APNGです。プレビューは比較のためループしますが、攻撃はゲームでは1回再生を想定しています。
- `character_02_stand_128.png` はパンチ動作の開始姿勢です。`comparison.gif` は3動作を並べた確認用です。

走行はその場で走る素材です。ゲーム側で主人公の座標を右へ移動してください。攻撃中はゲーム側の移動を停止します。パンチはジャブ、ストレート、フックの3打で、攻撃判定の候補をJSONに記録しました。回転蹴りは足元に金色のエネルギーを溜め、背面姿勢を経て右へ蹴り、構えに戻ります。回転の4原画は各1/24秒で素早く再生します。

## 制作元と検証

各 `source/generated_atlas.png` は高解像度の生成原画、`source/prompt.txt` は生成指示です。共通 `source/export.py` はフレームの分割、配置、パレット整理、透過PNG、APNG、GIF、JSONとZIPの再書き出しを行う編集可能なPythonソースです。PillowとNumPyが必要です。生成原画のPNGを編集してから実行すると再書き出しできます。

納品形態はフレームアニメーションです。関節ごとの独立パーツやボーン付き編集ファイルは含みません。回転蹴りのエネルギーはキャラクター画像と合成済みです。原画間の顔や衣装には生成由来の小さな描画差があります。

`verification.json` は画像寸法、透過、2pxドット格子、キャンバス内の余白、開始・終了原画の一致を確認した記録です。原画一覧も目視で確認し、回転蹴りの背面姿勢とエネルギーの方向を確認しています。
