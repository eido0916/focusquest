# キャラクター04：重騎士アニメーション

参照元は `../reference/4.png`。茶髪、銀の板金鎧、青い下衣、茶色の革帯、青縁の白い前垂れを残し、両手で扱う大剣を追加しています。128×128px、右向き、背景透過のミニキャラドット絵です。

|動作|原画|24fps連番|時間|ゲームでの再生|
|---|---:|---:|---:|---|
|run：走行|8枚|16枚|約0.667秒|ループ|
|slam：停止して大剣を振り下ろす|8枚|36枚|1.5秒|1回|
|charged_sweep：構え・蓄力・薙ぎ払い|12枚|48枚|2秒|1回|

走行は左右の脚で接地、沈み込み、蹴り出し、短い空中姿勢を描き分けています。接地後を3/24秒、空中姿勢を1/24秒保持し、鎧の重さを表現しています。走行画像はその場で走る素材なので、ゲーム側で座標を右に移動してください。攻撃中は移動を停止します。

振り下ろしは両手で持ち上げ、短い溜めを挟み、右前方へ斬り下ろして構えに戻ります。薙ぎ払いは大剣に金色のエネルギーを溜め、体をひねって横に払います。刀身とエフェクトは画像に合成済みです。

## 使用方法

- `frames/`：原画の透過PNG。
- `frames_24fps/`：保持時間を展開した24fps用PNG連番。番号順に再生します。
- `character_04_*_sheet.png`：128px単位のスプライトシート。左から右、上から下の順。
- `animation.json`：原画の保持時間、連番対応、配置変換、攻撃判定タイミングの候補。
- `preview/animation.gif`：2倍表示の確認用。時間は10ms単位に丸めています。
- `preview/animation.png`：128pxの透過APNG。
- `preview/keyframes.png`：原画一覧。
- `comparison.gif`：3動作の比較。攻撃終了後は構えを保持します。

原点はキャンバス左上、Xは右、Yは下。基準の足元は `(60,114)`。プレビューは比較用にループしますが、ゲームでは攻撃を1回再生してください。64×64の論理ドットを最近傍法で2倍にしているため、最終画像のドット格子は2px単位です。

## 編集元と検証

組み込みimagegenで制作しました。各 `source/generated_atlas.png` は高解像度の生成原画、`source/prompt.txt` は生成指示です。共通 `source/export.py` は分割、配置、減色、PNG/GIF/APNG/JSON/ZIP書き出しの編集可能なPythonソースです。PillowとNumPyが必要です。原画PNGを編集して実行すると再書き出しできます。

納品はフレームアニメーション素材です。関節ごとの独立パーツやボーン付きファイルは含みません。小さい表示に合わせて装飾を省略しており、生成原画間には顔や鎧の小さな描画差があります。元のプロフィール画像は上書きしていません。

`verification.json` に透過、寸法、ドット格子、余白、開始・終了姿勢、再生時間の確認結果を記録しています。
