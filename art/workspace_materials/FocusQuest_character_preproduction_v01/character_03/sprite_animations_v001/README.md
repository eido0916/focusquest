# キャラクター03：侍アニメーション

128×128px、右向き、背景透過のミニキャラドット絵です。参照元は `../reference/3.png`。黒髪、青い羽織、白い襟と袖口、濃紺の服、青い帯と脚紐、草履を残し、刀と左腰の鞘を追加しています。

|動作|原画|24fps連番|時間|ゲーム内の再生|
|---|---:|---:|---:|---|
|run：走行|8枚|16枚|約0.667秒|ループ|
|iai：停止して居合|8枚|36枚|1.5秒|1回|
|energy_flurry：構え・蓄力・乱舞|16枚|48枚|2秒|1回|

## 素材の使い方

各動作の `frames/` は原画PNG、`frames_24fps/` は保持時間を展開した24fps用PNG連番です。原画の保持時間と攻撃判定候補は `animation.json` に記録しています。スプライトシートは128px単位で左から右、上から下の順に読みます。

キャンバス原点は左上、Xは右、Yは下。キャラクターの足元基準は `(60,114)` です。走行はその場で走る素材なので、ゲーム側で座標を右へ移動してください。攻撃時は移動を停止します。走行の接地・沈み込み・蹴り出し・空中姿勢を左右脚で作り分けています。

居合は右手で刀を抜き、左手で鞘を支え、斬り抜けたあと納刀します。乱舞は刀に青いエネルギーを溜め、異なる方向の斬撃を続けて構えへ戻ります。エネルギーと刀の軌跡は画像に合成済みです。

`preview/animation.gif` は拡大確認用、`preview/animation.png` は透過APNG、`preview/keyframes.png` は原画一覧です。プレビューは比較のためループします。GIFの時間は10ms単位に丸めています。厳密な24fps再生にはPNG連番とJSONを使用してください。

## 編集元

各 `source/generated_atlas.png` は高解像度の生成原画、`source/prompt.txt` は使用した生成指示です。画像生成には組み込みimagegenを使用しました。共通 `source/export.py` は分割・配置・減色・PNG/GIF/APNG/JSON/ZIP書き出しの編集可能なPythonソースです。PillowとNumPyが必要です。原画PNGを編集してから実行すると再書き出しできます。

納品はフレームアニメーション素材です。関節ごとの独立パーツやボーン付き制作ファイルは含みません。小さい表示に合わせて装飾を簡略化しており、生成原画間には顔や服の小さな描画差があります。元のプロフィールイラストは上書きしていません。

`verification.json` に寸法、透過、2pxドット格子、見切れ、開始・終了姿勢、時間の検証を記録しています。
