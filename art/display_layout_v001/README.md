# 縦画面・横画面の表示修正

ホーム、キャラクター、冒険選択、設定、集中時間の選択、実行中の集中タイマーは縦画面です。2026年10月30日のユーザー訂正により、横画面は集中・冒険の戦闘画面だけに限定しました。

縦画面は390幅を基準としたレイアウトを画面幅へ拡大し、文字・アイコン・ボタン・背景を同じ比率で表示します。大きな縦長画面で本文だけが小さくなる問題と、ホーム下部の過剰な余白を改善しました。横長のウィンドウを手動で維持した場合は、縦レイアウトを中央へ高さに合わせて表示します。

Windowsは縦長ウィンドウで起動し、画面遷移時にモニターの作業領域とDPIに収まる縦長・横長サイズへ切り替えます。モバイルでは画面方向を指定し、端末が方向指定を反映しない場合も横画面の表示領域を回転させます。

画面方向はルートと各実行画面の状態をまとめて管理するため、戦闘→集中タイマーでは縦に戻ります。集中タイマーは当初のデザイン案どおり、残り時間・進捗の下へ戦闘表示、サウンド、中断ボタンを配置します。

実装：`mobile/lib/core/widgets/quest_display.dart`、`mobile/lib/app.dart`、`mobile/windows/runner/`、集中タイマーおよび各戦闘画面。

検証：`scripts/verify-quest-display.ps1`。メニュー4画面を3サイズ（添付と同じ1031×1792、1280×720、390×844）で描画し、文字を含む表示全体が実際のウィンドウ範囲へ拡大されることを確認しています。ルート遷移と向きの復帰テスト、既存のホーム・集中画面20レイアウトテストを合わせて24テストが合格。静的解析は `validation-analyze.log`、テスト結果は `validation-tests.log` に保存しています。
