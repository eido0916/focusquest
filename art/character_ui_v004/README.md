# キャラクター画面 v004

添付「蒼き城の狂戦士キャラクター画面.png」との差を詰めた改訂版です。

- 冒険者情報：上辺中央の見出し枠、細い金の縁、四隅の金飾りへ変更。
- 能力値の羊皮紙：白い花飾りを外し、金の蔓飾りと青い中央装飾へ変更。
- 操作ボタン：中央の宝石を外し、細い金枠と左右の小さな飾りへ変更。
- レベル上の飾り：横長の金の冠飾り。名前とレベルの区切りは菱形付きの金線。
- 余白、名前の文字サイズ、人物表示、下部ナビゲーションの高さを調整。

個別PNG19点。文字・数値・操作はFlutterから実データで表示します。
冒険者情報の現在の称号の補足文は表示しません。
装備操作・装備加算・装備ドロップは廃止済みです。
男性・女性の職業イラスト、職業紋章、原画アニメーションは保持しています。

`materials/` はアプリで使用する素材、`originals/` は新規生成3点の原本、
`previews/` はFlutterで出力した実画面です。
以前のv003素材・APKは保持しています。

生成プロンプトは `prompts.md`、PNG寸法とSHA256は `manifest.json`。
金の冠・区切り線の再現可能な描画コードは `scripts/package-character-ui-v004.ps1` にあります。
