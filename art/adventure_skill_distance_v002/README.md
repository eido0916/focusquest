# 冒険スキルの着弾位置 v002

前回の剣士の間合い修正に続き、遠距離職の大きな命中演出が主人公の前で先に出てしまうずれを修正した。

- 溜めの原画は主人公の位置に表示する。
- 放出後は飛び道具を実際の移動座標に表示し、到達前に敵のHPを減らさない。
- 魔法使い・魔剣士・陰陽師・天使・悪魔の大きな命中原画は、着弾が確定した位置へ表示する。動作終了後に到達した場合も表示する。
- 弓・銃は飛行中の矢・弾と命中表示を使い、三連射の発射数・威力を維持する。
- 遠距離スキルの命中演出は0.35秒保持し、既存の原画コマを切り替える。元のPNG・補間なし・ポイントサンプリングを維持する。
- 剣士・鎌使い・バーサーカーの距離を取る斬撃はv001のまま維持。

`previews/` は放出直後と着弾時のFlutter実描画。`index.html` で比較できる。

検証: 男女5職について着弾前のHP保持、主人公付近に大きな命中原画が出ないこと、着弾位置の画素変化、主人公側に命中原画が残らないこと、単発ダメージ・演出終了を確認。魔法使いは男女のボス戦も追加確認。剣士の12距離条件、既存の効果表示・遠距離・飛行表示の回帰検証も実行。ログは同フォルダ。

最終結果: 基本30件とコマ境界・ボスを含む着弾12件（重複を除く32件）が成功。静的解析は指摘なし。Windows Releaseビルド成功後、最後の境界調整も含む検証済みコードを別途コンパイルし、同一エンジンの既存起動フォルダへ反映。3186アセットを照合し欠落なし。実行コードのSHA256一致とアプリの応答を確認。
