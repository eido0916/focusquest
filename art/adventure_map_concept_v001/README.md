## 提案

現在の章を一枚のドット絵マップとして見せ、4つのステージを道で結ぶ。背景そのものを冒険の進行表にし、選択したステージの情報と「挑戦する」を下側にまとめる。従来の青・金の装飾、日本語の明朝体、下部4タブを継承する。

- クリア済み: チェックと「クリア済み」。ノードを押すと詳細を開き、「もう一度挑戦」で再挑戦できる。
- 挑戦可能: 旗・青い宝石・金の輪と「挑戦可能」。未クリアで挑戦できるのは直前のステージをクリアした次の1つ。
- 未解放: 鍵・灰色のノード・薄い霧。押したときは必要な直前ステージのクリア条件を表示し、挑戦ボタンは出さない。現在の章の4ノードは見せるが、未解放地点の敵の詳細は伏せる。
- 章ボス: 4番目のノードを王冠で区別。解放条件は他のステージと同じ。
- 次の章: 小さなシルエットの予告と解放条件だけを表示。それ以降の章の詳細は未表示にする。
- 過去の章: 「クリア済みの章へ」から選べる。現在の章のクリア済みステージも直接押せる。進行状況や再挑戦の機会は失わない。

初回はStage 1を旗付きで選択。Stage 4をクリアすると次章が解放され、次章へ進む導線を出す。全36ステージという全体像は旅の記録で伝え、未踏の全章を長い一覧で並べない。

## 画面構成

コンパクトな冒険の書ヘッダー → 現在の章と4ステージの進捗 → ドット絵マップと4ノード → 選択ステージの詳細・挑戦 → 次章の予告 → クリア済みの章への入口 → 既存の下部ナビ。

選択パネルは選んだノードによって「挑戦する」「もう一度挑戦」「解放条件」に切り替える。タップだけで戦闘を始めず、詳細から挑戦を確定する。選択状態と挑戦可能状態を混同しないよう、選択枠と進行の旗を別に扱う。

小さい画面では地図と情報を縦スクロールできるようにし、下部ナビを固定する。ロック状態は色だけに頼らず、鍵と文字でも示す。装飾・背景・道・ノード・文字・操作ボタンは実装時に別レイヤーにする。
