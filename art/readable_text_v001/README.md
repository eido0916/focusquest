# 文字位置・読みやすさの調整

2026年10月30日。既存の素材・配色・書体と、主要画面を縦スクロールさせない構成を維持して調整。

- パーティー：カード内の幅不足を解消し、空席表示と操作ボタンの文字を中央へ揃えた。補足文字を14pxへ拡大。開始条件には濃い背景を付け、無効ボタンも読み取れる濃さにした。
- ホーム・タイマー：共通文字の下限を14pxへ。小さい操作ボタンは16pxへ拡大。
- 冒険・見出し・下部メニュー・キャラクター：小さい補足とメニュー文字を拡大。
- 集中時間選択：小さくなっていた表示に14pxの下限を設定。
- 設定：幅による文字の縮小を抑制。長い説明は情報ボタンから読む形式へ。権限名は意味の区切りで改行し、設定ボタンは一行で収まる幅を確保。リセット前の説明・確認はダイアログで維持。

## 確認

関連94件を複数の実行で確認。ホームなど4画面のサイズ違い、設定、パーティー、集中時間選択、タイマー、冒険マップ、開発者用の職業変更とリセットを対象とした。280px幅、小型320×568、縦長、タブレット、文字160％を含む。

パーティーの中央位置と、390×844の設定説明が画面へ収めた後も13.5px以上で表示されることをテストに追加した。変更箇所の静的解析は指摘なし。
