# 冒険画面 v003

ユーザーの二枚目 `reference-design.png` を基準に再実装。旧版は保存。

- 第1章の背景はヘッダーから画面下まで連続する一枚の `landscape.png`。画面全幅のスクロールコンテンツの Stack で一度だけ描画する。中央地図の別画像・画面固定の別背景・空のグラデーションを撤去。
- 草原サムネイルは同じ風景の切り出し。横視点の戦闘背景を表示しない。
- 幽霊船の予告、金枠のボスメダルは独立して新規制作。従来の金装飾フレームは継続利用。
- 霧2枚、光る道、挑戦中の光、コンパス、旗、王冠をそれぞれ個別SVGからPNG化。画像に文字は焼き込まず、ステージ番号・ロック・進行状態は動的に表示。
- 数字の `TextStyle` を `inherit: false` にし、計測用 TextPainter と実際の Text の条件を統一。以前は Material の文字間隔等が表示時に継承され、計測結果と違う位置になっていた。全36番号×ロック有無の72通りを、異なる親スタイル下の実描画画素で検査。
- 第2章以降も背景は一度だけ描画。ステージ順の解放・クリア済み再挑戦・章履歴は維持。
- 冒険タブのナビゲーションサイズを画面幅に応じて調整し、画面下の章履歴に余白を確保。

## 素材

`originals/`: Built-in image_gen による原画3枚。プロンプトは `generation-prompts.json`。
`vectors/`: 編集可能な個別SVG。
`materials/`: アプリへ配置した11点のPNG。
`manifest.json`: 寸法とSHA-256。
`asset-verification.json`: 原画パッケージとアプリ配置PNGの一致検査。
`material_catalog.png`: 素材一覧。
`previews/`: Flutterの実描画画面および参考画像との比較。

再生成: `node scripts/package-adventure-map-v003.cjs`。
描画テスト後の比較・素材照合: `node scripts/review-adventure-map-v003.cjs`。
