# キャラクター画面・ドット絵版 v007

2026-10-29。ユーザーが選んだA案（全身を主役にした画面）をFlutterのキャラクター画面へ実装。

- 16職×男女の32体を個別に制作。`standing/male/`、`standing/female/` に128×128px透過PNGを収録。
- 既存の全身イラスト・戦闘用原画・顔アイコンを各体の参照に使用。`references/` が制作時の照合資料。
- 武器、装備、服、髪色・髪型を参照と照合。男性拳闘士の頭巾、男性侍の長髪は採用せず、元の設定に合わせて再制作した。
- 女性アサシンの赤髪、魔法使いの紫髪、女性ガンナーの濃い茶髪を引き継ぐ。
- 64pxの論理格子を2倍にして128pxで納品。2×2 RGBA画素の完全一致、透明余白、アルファ0/255を検証。足元の基準はy=120px。
- 静止画のみ。戦闘原画やアニメーションの再生方法を変更しない。元のイラスト・旧UI素材も上書きしない。

画面は新作のドット絵背景、コードで描く青金の段差枠とアイコン、既存の顔アイコン、全身立ち姿で構成。文字・能力値・EXP・称号変更・冒険者証は実際のアプリ状態と操作を保持。レベル表示の右余白も保持する。

`index.html` は32体の参照比較と実装画面プレビュー。`originals/` に画像生成ツールが出力した高解像度原画、`manifest.json` に個別PNGの寸法・格子検証・ハッシュを記録。

画像生成には組み込み `image_gen` を使用。各体・背景の最終プロンプトと参照ファイル、出力元は `generation-final.json` に保存。`generation.json` は最初の12体時点の制作記録。

再パッケージ：`node scripts/build-character-pixel-v007.cjs package`

検証：`scripts/verify-character-pixel-v007.ps1`。作業中の別ビルドと競合しない一時ディレクトリで、キャラクターUIに必要な素材だけを束ねてテストする。アプリ本体のpubspecには本番用素材を登録。

検証結果：57件成功（32体のPNGと格子、画素比1/1.5/2/3倍、9画面サイズ×通常/1.6倍文字、称号操作、男女全職のホームとキャラクター画面の対応）。実画面確認でEXP塗りの高さを修正し、塗りの寸法検証を追加して18通りのレイアウトを再検証、全件成功。静的解析も問題なし。

`standing-32-characters.zip` は128px立ち姿32体、男女の一覧画像、manifestをまとめた素材パック。高解像度原画は `originals/` に別途保存。
