# 冒険者証 v001

男女16職業、32種類。各カードは1536×2304pxの独立PNG。

- `templates/`: 既存キャラクター画像、証書背景、項目名、役職名、発行ギルド、Eishinを含むゲーム用カード素材。個人情報欄は空欄。
- `previews/`: 名前「見本」・Lv.8・126時間40分・1284体・18日・8ステージの架空データを入れた文字込み完成見本32枚。実プレイヤーの実績ではない。
- `male-review-1.png`〜`female-review-2.png`: 全32枚の確認用一覧。
- `parchment-background.png`: imagegenで生成した背景。参考画像の羊皮紙、装飾枠、城・山の線画、紋章、封蝋を縦長証書へ再構成。
- `background-prompt.txt`: 内蔵imagegenに渡したプロンプト。

キャラクターは `mobile/assets/images/lobby/portraits/` の現行男女素材を直接トリミング・描画。顔を再生成しない。元画像は上書きしない。称号帯は職業に合わせて青・緑・紫・赤・金茶を使用。

## アプリ

キャラクター画面上部の「冒険者証」アイコンで開く。「PNG保存」で表示中と同じ画像を保存し、保存先を表示する。Androidはアプリの外部ファイル領域、その他はドキュメント領域。写真ライブラリへの登録やSNSへの送信は行わない。

`CertificateData.fromState` が実データを取得し、`CertificateRenderer.render` が文字を配置する。Lv.1〜7は同じ段階の称号、Lv.8以上は第8段階。2026-10-11にユーザーが提示した16職業×8段階の一覧をそのまま採用（剣士の第8段階は「剣聖」）。

総集中時間は成功済み・終了済み集中セッションの合計。最深到達はクリア済みステージの重複を除いた件数。冒険日数は初回プレイ日からの暦日数（当日を1日）。冒険者番号は初回保存時に乱数で発行し、職業・性別を切り替えても同じ番号を保持。

初回プレイ日を新規保存する。導入前から存在し日付が不明な保存データの発行日は「未記録」、冒険日数は記録のある集中実施日数を表示する。過去の日付を捏造しない。

累計討伐数はこの機能導入後から記録。以前の討伐数は保存されていないため復元できない。通常冒険は倒された敵オブジェクトを重複なく数え、退出時に勝敗に関わらず保存。保存失敗時はステージ選択で再保存可能。集中の自動戦闘は画面と同じ決定的計算で終了・中断時までを集計し、集中結果と同じ保存トランザクションで加算。パーティー集中は各メンバーの敵を含むチーム討伐数。処理IDで再保存・再表示時の重複加算を防ぐ。

## 再生成

PowerShellで `mobile/` を作業フォルダーにし、`FQ_CERTIFICATE_EXPORT` にこのフォルダーの絶対パスを設定して `flutter test --no-pub test/certificate_assets_test.dart` を実行する。日本語フォントとFlutter Canvasによる組版・元素材の合成で再生成する。背景のみimagegen製。
