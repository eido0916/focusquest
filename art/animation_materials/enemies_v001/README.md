# 敵3種類：128×128ドット絵と左向き移動

スライムは青緑の弾むゼリー、ゴブリンは緑肌・革服・棍棒を持つ小走り、ドラキュラは黒髪・白い肌・赤い裏地のマントを着た浮遊移動。既存ミニキャラの粗いドット、輪郭、少ない色、デフォルメに合わせ、内蔵image_genで各敵につき6コマ原稿を1枚ずつ生成。

## 各敵フォルダ

- slime/、goblin/、dracula/。各敵の番号00〜05は再生順。
- frames/：128×128透過PNG6姿勢。動作だけのその場ループ。
- cycle_24fps/：24fps・12枚・0.5秒。各姿勢を2フレーム保持。
- move_left_24fps/：24fps・24枚・1秒。動作を繰り返しながらキャンバス内で実際に右から左へ24px進む連番。単発再生。
- preview/move_left.gif：384×160の確認ステージを右から左へ進む2.5秒プレビュー。繰り返し時には開始位置へ戻る。
- preview/move_left_128.png：128×128移動連番のAPNG。
- preview/cycle.webp：透過のその場動作ループ。
- preview/all_6_frames.png：番号入り拡大一覧。
- *_stand_128.png：先頭姿勢の静止PNG。スライム・ドラキュラは移動サイクルの先頭姿勢で、独立した待機アニメーションではない。
- *_sheet_128.png：128×128セル、3列×2行の透過シート。
- animation.json：寸法・向き・時間・移動量・連番。
- source/generated_sheet.png、prompt.txt：生成元と正確な指示。
- verification.json：全フレームのサイズ、透明、2×2ドット、見切れ、6姿勢の相違を検証。

## 共通ファイル

enemies_move_left.gif：3種類を同じ画面で移動比較。enemies_overview.png：見た目の一覧。source/export_enemies.py：分割・共通色・配置・書出し元（Python、Pillow、NumPy）。

論理64×64を128へNEAREST整数2倍、各敵の全周期で24色以内、透明0/255。生成原稿内の位置ずれを補正し、動く領域の余白を統一。スライムの上下は跳躍、ゴブリンは接地・膝の送り、ドラキュラは浮遊とマントの変化として整理。

実装にはその場のcycle_24fpsを使い、ゲーム側で左へ移動させる方式と、move_left_24fpsに焼き込んだ24pxの移動を使う方式のどちらかを選ぶ。両方の移動量を同時に加算しない。GIFは10ms単位に丸め、正確な24fpsはPNG連番とanimation.jsonの時間を使用。敵の攻撃・被弾・倒れる動作は今回含まない。
