# キャラクター01：剣の溜め・振り下ろし・短い衝撃波

既存のミニキャラの右向き振り下ろしを使用し、青白いエネルギーを剣へ溜め、振り下ろした後に小さな衝撃波が右前方へ進んで消える単発スキル。既存の原画、待機、走行、通常攻撃は変更していない。

## 内容

- frames/character_01_skill_wave_00.png〜11.png：128×128の透過PNG12コマ。最後は最初と同じ待機。
- frames_24fps/：24fpsの表示用連番36枚、1.5秒。各姿勢を保持するため36種類の異なる絵ではない。
- character_frames/、effect_frames/：各コマのキャラクター層とエフェクト層。重ねると完成PNGに一致。
- effects/：8種類の生成エフェクトの個別透過PNG。これはキャラクターの可動パーツではない。
- character_01_skill_wave_sheet_128.png：4列×3行の透過シート。
- preview/all_12_frames.png：番号入り一覧。
- preview/skill_wave.gif：背景付き繰り返し確認。skill_wave.webpとskill_wave.png：透過WebP/APNG。
- animation.json：24fpsの順番、保持時間、放出のフレーム、寸法、合成配置。
- source/generated_fx_atlas.png、prompt.txt：内蔵image_genによるエネルギー素材の原稿と正確な生成指示。
- source/export_skill.py：既存攻撃PNGと生成エフェクトの配置、共通色、再書出し元。
- verification.json：サイズ・透明・ドット・見切れ・レイヤー再合成一致・開始終了一致の検査。

## 構成と時間

構え→弱い溜め→強い溜め→頭上で最大溜め→振り下ろし→衝撃波放出→前進→減衰→復帰。剣に沿うエネルギーの輪郭は、画像中の握り点と剣先を指定して配置。波は画面右へ約20px進み、薄く崩れて消える。遠くまで届く巨大な斬撃ではなく、短い衝撃波。

24fpsの保持数は3,5,5,7,1,2,2,2,2,2,3,2で計36フレーム、1.5秒。ゲームでは単発、確認用プレビューは繰り返す。厳密な時間はanimation.jsonのF/24秒を使う。

論理64×64、128はNEAREST整数2倍。キャラクターとエフェクトの共通32色以内、透明0/255。衝撃波用の余白を作るため、攻撃元画像を論理64に対して58のサイズで配置し、左へ寄せた。通常攻撃版と同じ表示倍率に揃えたい場合は、アプリ側の表示範囲か別エフェクト層の配置に合わせて再調整する。

放出タイミングは21/24秒。これは描画タイミングの記録で、ダメージや攻撃判定はまだ実装していない。走行から停止する遷移、敵への命中、四方向、キャラクターの独立可動パーツは含めない。
