# キャラクター01：走行から通常攻撃／スキルへつなぐ素材まとめ

これまでの右向きミニキャラ素材を2本の確認用シーケンスにまとめた。どちらも走行1秒→停止した構え4/24秒→既存のその場の動作→構えへの復帰。剣やスキルを走行中に同時発動する新しい動作は、このまとめには含まない。

- run_then_attack/：走行→停止→振り下ろし。24fps、52枚、約2.17秒。
- run_then_skill/：走行→停止→剣に溜め→振り下ろし→短い衝撃波→復帰。24fps、64枚、約2.67秒。
- 各フォルダ frames_24fps/：128×128透過PNG連番。保持中は同じ画像が複数枚になる。
- 各フォルダ preview/animation.gif：背景付き確認。animation.webpとanimation.png：透過WebP/APNG。
- 各フォルダ animation.json：全フレーム順・時間・走行／停止／攻撃の区間。
- comparison.gif：2本を同時再生。通常攻撃側が先に終了すると、構えで待機。
- sequence_overview.png：主な姿勢の比較。
- original_assets/：走行、通常攻撃、スキルの以前の納品フォルダをそのままコピー。個別キーコマ、エフェクト層、生成元、仕様を収録。
- source/build_bundle.py：連番とプレビューの組立・再書出し元。
- bundle.json、verification.json：配置と検査。

単体素材の頭・身体の大きさに差があったため、比較用連結シーケンスでは整数ドットを維持するNEARESTでサイズ・足元・位置を合わせている。走行は元128を論理48へ縮小して(-1,14)へ、通常攻撃は論理58へ縮小して(-7,5)へ配置し、64から128へ整数2倍。スキルは既存128を維持。元の単体素材はoriginal_assetsに変更せず保存。

停止の区間は構えを保持する接続で、減速・足の踏み替えを描いた追加の遷移アニメーションではない。1枚の画像に右への移動量は含めず、ゲーム側で走行中の移動と停止を制御する。ゲームでは単発再生、プレビューは繰り返し。PNGとF/24秒が時間の正本。

128×128 RGBA、0/255アルファ、2×2等間隔ドット、見切れがないことを全フレーム検査。生成画像の描き直しは行わず、既存素材を組み合わせた納品。
