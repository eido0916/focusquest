# モンスター3種類：左向き攻撃

既存の敵画像を参照し、内蔵image_genで各敵の8コマ攻撃原稿を生成。元の移動モーションを上書きせず、新しいフォルダに整理。

- スライム：縮む→右へ溜める→左へ体当たり→反動→元の位置へ戻る。
- ゴブリン：棍棒を引く→頭上へ構える→左へ振り下ろす→振り終わり→復帰。
- ドラキュラ：手を上げて紫の魔力を溜める→左へ小さな魔力弾→弾の前進・消失→復帰。

## 各敵フォルダ

- frames/：128×128透過PNG00〜07。最後は最初と完全に同じ姿勢、異なる絵は7種類。
- frames_24fps/：24fps、24枚、1秒の単発攻撃。姿勢の保持により同一画像を含む。
- character_frames/とeffect_frames/：キャラクター層とエフェクト層。重ねると完成PNG。スライム・ゴブリンのエフェクト層は透明、ドラキュラは魔力弾・粒子。
- preview/attack.gif：背景付き繰り返し確認。attack.webpとattack.png：透過WebP/APNG。
- preview/all_8_frames.png：コマ番号入り一覧。
- *_attack_sheet_128.png：128セル、4列×2行の透過シート。
- animation.json：保持時間、発動・放出タイミング、フレーム順、位置、単発再生指定。
- source/generated_attack_sheet.pngとprompt.txt：生成原稿と正確な生成指示。
- verification.json：寸法、ドット、透過、見切れ、開始終了一致を検査。

enemy_attacks_comparison.gifは3種類の同時比較。source/export_attacks.pyは分割、位置調整、色整理と書出し元（Python＋Pillow＋NumPy）。

論理64×64から128へNEAREST整数2倍。スライムとゴブリンは24色以内、ドラキュラは魔力弾を含み32色以内を全周期で共通化。透明は0/255。各敵の姿と配色を参照した新しいポーズで、移動版の全ピクセルが同一になるものではない。

スライムの体当たりはフレーム内に踏み込み・戻りを含む。他2種はその場の攻撃。ダメージや衝突判定は未実装。発動・放出フレームは描画上の目安を記録し、アプリ側で調整する。ゲームは単発再生、プレビューは繰り返し。GIFは10ms丸め、正確な時間はPNGとF/24秒。
