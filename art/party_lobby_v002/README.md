# パーティー待機画面 v002

先に [配置案](design.md) を作成し、既存の城背景・青金装飾・書体を使って待機画面を再構成した。

- コードと招待を一枠にまとめ、4人のカードを低くした。通常の390×844画面ではカード幅75px以上を確認。
- 退出・解散を縮小対象の本体から分離し、画面下部へ固定。通信待ち中も退出できる。
- 退出要求の送信に失敗しても、端末内の参加状態・復帰情報を解除する。接続終了待ちは時間を制限する。
- 解散失敗の原因は公開サーバーの旧版。対応版を公開用ブランチに反映してRenderへデプロイし、Liveを確認。

サーバーコミット：`677ef9ba5e212257a27417c66930c5b150181067`

## 検証

- 画面テスト14件：390×844、320×568、横長画面、文字160％、1〜4人、ホスト・参加者。はみ出し・画面の縦スクロールなし、退出・解散のタップ位置を確認。
- 通信・操作テスト12件：作成・参加・満員・準備・同期開始・退出・リーダー移譲・解散・送信失敗時の退出。
- 変更したアプリコードの静的解析：指摘なし。
- 公開先 `wss://focusquest-party.onrender.com/party` で1人・4人の解散、全員への解散通知、旧コードの無効化を確認。`server/smoke_test.dart` で再実行可能。
