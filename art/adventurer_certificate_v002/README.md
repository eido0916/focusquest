# 冒険者証 v002 横長

参考画像2枚目の構成に合わせた2304×1536px（3:2）の完成PNG。16職業×男女の32種類。v001の原本・キャラクター素材は保持しています。

- `templates/`: ゲーム用素材32枚。既存のキャラクター、項目名、役職、発行ギルド、筆記体Eishin署名を含み、プレイヤー別の文字欄は空欄。
- `previews/`: 名前「見本」、Lv.8、126時間40分、討伐1,284、18日、8ステージの架空データを組み込んだ完成見本32枚。
- `current-screen-example.png`: 提示された現在画面の「たろう」、女性魔法使い、Lv.3（魔術師）、30分、討伐1,284、1日、1ステージ、AG-0421890、発行日未記録を横長に組み直した確認見本。保存データ自体を変更するものではありません。
- `materials/`: 額縁、称号帯、竜の封蝋、署名、ギルド紋章、項目アイコンを個別確認できる13素材。周辺の羊皮紙を含むPNGで、透過素材ではありません。
- `master-landscape.png`: 内蔵imagegenで参考画像を編集した背景原本。羊皮紙・罫線・称号帯・封蝋・署名を一体で制作。顔は生成していません。
- `master-prompt.txt`: imagegenに渡した制作指示。
- `male-review-1.png`〜`female-review-2.png`: 全32枚の確認用一覧。
- `titles.json`: ユーザー指定の16職業×8段階称号。

名前・称号・役職は右側の3行、実績はその下の2列、発行情報と署名は最下部へ配置。単色の角丸背景を重ねず、称号の文字を赤い装飾帯へ直接印字します。各欄も連続した羊皮紙へ印字します。封蝋は参考画像の翼を持つ竜の紋章、Eishinは右下の筆記体署名です。

アプリでは `CertificateData.fromState` の実データを `CertificateRenderer.render` で組版し、表示と同じPNGを保存します。Lv.1〜7は対応段階、Lv.8以上は最終段階の称号を1つだけ表示。最深到達はクリア済みステージ数、発行日は記録済み初回プレイ日。不明な旧データの発行日は未記録を維持します。

`mobile/assets/images/certificates_landscape_v002/` が現在の参照先。画像は横長、アプリ画面では縦持ちでも全体表示とピンチ拡大が可能です。

再生成: `mobile/` で環境変数 `FQ_CERTIFICATE_EXPORT` にこのフォルダーの絶対パスを設定し、`flutter test --no-pub --concurrency=1 test/certificate_assets_test.dart` を実行。Windowsでは日本語パスによるシェーダー問題と並行ビルドの競合を避けるため、ASCIIパスの独立コピーで検証しています。

検証結果: 32枚のテンプレート寸法検証・完成見本生成が成功。称号、保存データ互換性、実績集計、実データから2304×1536pxの表示画像生成、縦320×568px・横844×390pxの画面表示、保存ボタン有効化の5テストが成功。Flutter analyzeは指摘なし。全32件のキャラクター元画像SHA-256はv001と一致。端末へのアプリ更新・インストールはこの制作には含みません。
