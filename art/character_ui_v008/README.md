# キャラクター画面 v008

ユーザー提供の `reference.png` を基準に、単一の背景、詳細な静止立ち絵、青金の独立PNGを実装。

- `materials/`: 背景、見出し、名札、羊皮紙、能力値バー、操作ボタン、各アイコン。名前・数値・文字は画像に含めずFlutterから描画。
- `standing/male/`・`standing/female/`: 16職×男女、512×512透過PNG。v007の高解像度原画から細部を保持して再パッケージ。男性剣士は今回の参照に沿って新作。
- `originals/`: image_genで生成した背景と男性剣士の原本。背景案のうち参照に近い二案目を採用。
- `previews/`: Flutterテストによる実画面。375×662は参照と同じ縦横比。
- `manifest.json`: アプリ内PNGのサイズとSHA256。
- `generation.json`: 採用した生成プロンプトと原本。
- `index.html`: 参照・実画面・個別アセット一覧。

64px論理格子への縮小をメニューの立ち絵から取り除いた。静止立ち絵の変更であり、戦闘用128px原画、24fps保持、補間なしの再生方式は変更していない。旧素材は保持。

背景は画面内に一枚だけ描画。枠は個別PNGを9分割描画し、文字・数値・EXP、称号変更、冒険者証はアプリ状態と操作を保持。文字拡大時は能力値とボタンを縦へ組み替え、スクロールで操作できる。

アセットの制作・再パッケージは `scripts/build-character-ui-v008.cjs`。背景・剣士の原本パスを引数で指定する。青金の枠とアイコンは同スクリプトで個別に描き出したPNG。既存の画像生成原画を利用する他31体は外見を変更しない。

Windowsの統合版更新は `scripts/run-character-ui-v008.ps1`。通常の `lib/main.dart` を使用し、既存の保存データを引き継ぐ。

検証: 10画面サイズ × 文字倍率1.0/1.6の20レイアウトと、称号の保存・選択2件が最終版で成功。参照サイズのボタンがスクロール前にメニュー上へ収まることと、二重背景がないことを検証。32体の透過余白・画素比1/1.5/2/3・男女全職の割当ても確認。
