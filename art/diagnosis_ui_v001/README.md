# 冒険のはじまり — 登録・二択診断

2026-10-12の添付2画像を参照し、Flutter本体の初回登録と質問画面を制作。

## 個別素材

`source/` は生成した原寸PNG。アプリ用PNGは `mobile/assets/images/diagnosis/sanctuary_v001/` に配置。

- sanctuary.png: 空中神殿・浮島・石柱・水面の背景
- crystal.png: 青い魔法石・金の軌道輪・吊り装飾
- title-plaque.png: 紺色と金の見出し枠
- parchment-panel.png: 羊皮紙カード・薄い城と羅針盤
- sapphire-panel.png: 選択中の青いカード・名前入力枠
- confirm-button.png: 青い宝石調の決定ボタン
- orb-blue.png / orb-purple.png: 男女・A/Bの選択メダリオン
- compass.png: 金の羅針盤装飾

`manifest.json` に寸法、原寸素材、透明余白の切り出し範囲を記録。
`asset-sheet.jpg` は素材一覧。`scripts/package-diagnosis-ui.py` で再配置できる。

## 操作

名前は16文字まで。名前と見た目の入力後、全10問を1問ずつ表示。
回答を選択して「この答えで進む」で次へ。未回答では進めない。
戻ると選択を保持。最終問題は「診断結果を見る」。診断判定・結果保存・失敗時の再試行は従来の処理を使用。
文字、入力欄、選択状態、進捗はFlutterのウィジェットで描画。
小画面・横画面・大きい文字・キーボード表示時はスクロールで操作可能。

参照画像と各パーツは画像生成による再制作のため、画素単位で同一ではない。
キャラクターのドット絵・原画アニメーション素材は変更していない。

## 検証

診断関連2ファイルの静的解析: No issues found。
登録から10問の回答、結果確認、保存、保存失敗時の再試行を含む7件のテストに合格。
390×844・320×568・844×390、大きい文字（1.5倍）の表示を検証。
`previews/` にFlutterの実描画PNG、`index.html` にプレビューと素材一覧を保存。
中央背景に薄い青の陰影を重ね、文字と進捗の視認性を調整。
