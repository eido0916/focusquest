# キャラクター画面素材 v001

添付画面を参考に、濃紺・金の装飾ウィンドウと晴天の城・回廊背景を制作。組み込み先は `mobile/lib/features/character/presentation/character_screen.dart`。

- `originals/`: built-in image_genで制作した背景、ウィンドウ、装備スロット、アイコンアトラスの原画像。
- `mobile/assets/images/lobby/`: アプリ用PNG。装備スロットは外側の空白をトリミング。アイコンはアトラスから分割。
- `mobile/assets/images/lobby/portraits/`: 指定された「FQ_16職_ロビー用立ち絵_改訂版」の16枚を原画のままコピー。透過を保持し、男性16職に対応。女性版は以前の職業イラストを継続使用。
- `prompts.md` と `icon-prompt.md`: 最終生成プロンプト。
- `scripts/package-character-lobby.py`: 再パッケージ用スクリプト。
- `output/character_lobby/`: Flutterの実画面プレビュー。

ステータス・EXP・装備名・所持数は保存データから表示し、装備変更は既存の処理へ接続。仲間ウィンドウと編成操作は削除。横幅は従来の最大640を維持し、中央の立ち絵→ステータス→装備の縦構成で画面内へ配置。文字と画面全体の縮小を廃止。タブレットの本文は20px、見出しは28pxに拡大し、装飾を避ける内側余白を確保。ウィンドウは文字の自然な高さに合わせ、立ち絵領域で全体の高さを調整する。高さ不足や文字拡大時にはステータス／装備のタブで切り替える。通常の縦長タブレットでは、メイン画面はスクロール不要。所持アイテムはボタンで専用一覧を開く。城の背景を画面全体に1枚で表示し、左右の背景の境目を解消。下部メニューは現行のホーム／キャラクター／設定／冒険の4項目。原イラストと既存アニメーション素材は維持。
