# 冒険バトルUI v001

2026-10-30追記：現在の冒険ではオート機能を削除し、攻撃・技は手動操作に変更しました。以下はv001制作時の記録です。変更記録は [手動操作への変更](../adventure_manual_controls_v001/README.md) を参照してください。

「草原ステージの忍者RPG画面.png」を参考に、金縁・濃紺パネルと赤青の丸ボタンを制作。
組み込み先はFlutterの `PlayableStagePage`。横画面はステージ全面にHUDを重ね、縦画面は上部表示を積み重ねます。

## 個別素材

`frames/` のPNGは外周透過。文字・アイコン・HPの緑の量・フェーズの点はゲーム側で重ねます。

| ファイル | 用途 |
| --- | --- |
| status_panel.png | プレイヤー情報のパネル |
| portrait_frame.png | 顔画像を囲む枠。中央も透明 |
| hp_frame.png | HPゲージの金縁 |
| stage_banner.png | 中央上のステージ名バナー |
| phase_panel.png | 右上のフェーズ・残り敵数・進行状況 |
| attack_button.png | 赤い通常攻撃ボタン枠 |
| skill_button.png | 青いスキルボタン枠 |
| auto_button.png | 小さなオートボタン枠 |
| utility_button.png | 音声・一時停止・再開始の共通角枠 |
| caption_frame.png | 攻撃間隔・命中数の共通下枠 |

`raw/` は組み込み前の生成原本。`manifest.json` は寸法と余白の切り出し座標、`prompts.json` は生成プロンプト集。
画像生成には内蔵 `image_gen` を使用し、1素材ずつ生成しました。透明外周の余白を整理し、描画は保持しています。
キャラクター原画・アニメーション・既存背景は変更していません。

`frame_catalog.png` は素材一覧、`adventure_preview.png` は実際のFlutter画面です。
実装用のコピーは `mobile/assets/images/adventure_ui_v001/` に保存。

## 動作

- 上部に職業・レベル・HP、ステージ名、3段階のフェーズと残り敵数を表示。
- 攻撃・スキルは既存の使用条件を維持。オートは使用可能なスキルを優先し、通常攻撃を自動実行。
- 一時停止・アプリが背景に移った際はオートも停止。再開後に続行。
- 小型画面でも操作用ボタンは44px以上。一時停止・結果表示の間は戦闘操作を遮断。
- 戻るボタンは左上。クリア後のステージ選択への遷移を維持。
