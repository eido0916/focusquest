# スライム・ゴブリンの表示差し替え

素材元は取り込み済みの `art/animation_materials/enemies_v001/`。
各128×128セル、3列×2行の透過PNG、左向き6姿勢を0.5秒でループ再生します。
アプリ用コピーは `mobile/assets/images/enemies/`。元素材は変更していません。

- 移動：その場のスプライト周期＋既存戦闘状態のX移動。画像に焼き込んだ移動連番は使わず、二重移動を防ぎます。
- 停止：主人公前の停止位置でX移動のみ止め、移動モーションはその場で繰り返す。
- 被弾：短い明滅。HPが残る場合は移動・停止を継続。
- やられ：専用素材がないため、移動ポーズを固定してFlameの描画変形で実装。スライムは潰れて消え、ゴブリンは後方へ傾いて消えます。0.5秒で既存の敵削除と同期。
- 攻撃：実装・素材読み込みなし。主人公への攻撃・ダメージ処理は追加していません。

移動素材は `EnemyMotionAssets` で共通ロードし、各敵インスタンスから再利用。
敵HP、停止位置、出現速度、主人公の攻撃、討伐・EXP処理は既存のままです。
ユーザー指定により、テスト・静的解析・実機確認は行っていません。
