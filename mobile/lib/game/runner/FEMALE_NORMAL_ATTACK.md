# 女剣士：走りながらの通常攻撃

スキルではなく、1回の通常攻撃。元画像は変更・削除せず、同名コピーをアセットに保存した。
全30候補を5分割で出力して個別に目視した。黒く見えた背景は実際にはアルファ0で、背景除去は不要。
等分時に人物・剣が枠をまたぐため、採用コマは元画像のアルファ連結成分で分離した。
重なりで分離が破綻するコマは採用しない。画像を生成・描き直していない。

### 素材上の制約

斬撃の中間候補09・12–14が隣の人物と重なっているため、上側11から振り抜き16への中割りは少ない。
破損コマを残すより短いキーポーズで接続する構成を選んだが、完全に滑らかな剣軌道の保証はできない。
さらに滑らかにする場合は、この区間の人物が重ならない元フレームが必要。勝手な補間描画・デザイン変更はしていない。

## 時間と攻撃判定

`selection.json`を設定源とし、ビルダースクリプトが実行用`normal_attack.json`を生成する。
PNGの再生成なしで実行用JSONの`stepTimes`を編集できる。全体の速度はロード時`timeScale`でも変更可能。

| 最終コマ番号（1始まり） | 元コマ | 秒 |
|---|---|---|
| 1–3 | 01,02,03 | 各0.050 |
| 4 | 06 | 0.055 |
| 5–6 | 07,08 | 各0.065 |
| 7 | 11 | 0.055 |
| 8 | 16 | 0.085 |
| 9 | 17 | 0.070 |
| 10 | 18 | 0.060 |
| 11–15 | 19,20,22,23,24 | 各0.050 |

- 合計0.855秒、ループなし。
- 攻撃判定：最終8–9コマ（元16・17）、開始0.390秒、終了0.545秒。`activeHitIndexes`は0始まりの`[7,8]`。
- ダメージコールバックは判定開始時に1回だけ。長いdtで判定区間を通過しても呼び落とさない。
- 0.545秒から`runAttackRecovery`、0.855秒に`run`へ戻る。
- 再発動は攻撃・復帰中とも拒否。通常走行は22,23,24を0.07秒/コマでループ。
- 移動：通常80単位/秒、攻撃中70%（56単位/秒）。右方向のみ。演出エフェクトなし。
- 足元と胴体位置の共通アンカー、共通透過キャンバスを使用。シート単位の倍率で見た目サイズを補正し、ポーズごとの剣の高さで体のサイズを変えない。

## 組み込みコード

実装全体は`female_run_attack_assets.dart`と`female_run_attack_component.dart`。
既存男剣士の`HeroComponent`と蒼閃は変更していない。このコンポーネントは追加用で、既存の集中画面のヒーローを自動で差し替えていない。
女剣士のスキル画像は今回未提供なので、男剣士のスキル画像に切り替えるような接続は行っていない。

```dart
import 'package:flame/components.dart';
import 'female_run_attack_assets.dart';
import 'female_run_attack_component.dart';

// FlameGame.onLoad内。targetResolverは既存戦闘側の処理に置換する。
final assets = await FemaleRunAttackAssets.load(this);
final player = FemaleRunAttackComponent(
  assets: assets,
  position: Vector2(345, 405),
  onNormalAttackHit: (hitArea) {
    // 敵がいない場合は何もしない。
    // 既存戦闘処理でhitAreaに入る敵を選び、通常ダメージを1回適用する。
  },
);
await add(player);

// 通常攻撃の発動。スキルのクールダウンには登録しない。
player.playRunAttack();
```

固定画面のFocusQuestでは、`onAdvance`に背景/世界側の移動処理を渡すとプレイヤー自身の画面座標は固定される。
既存の背景が既にスクロールしている場合、二重スクロールを避けて`onAdvance: (_) {}`で既存処理に任せる。
この場合も人物の走行ポーズは止まらない。物理移動をする横スクロールゲームでは`onAdvance`を省略する。
ダメージは既存シミュレーションかこのコールバックのどちらか一方だけを所有者にする（二重適用しない）。
