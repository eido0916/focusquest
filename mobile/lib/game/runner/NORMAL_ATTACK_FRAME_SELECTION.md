# 走行二連斬り：通常攻撃の素材選定と実装

これは通常攻撃です。蒼閃の35フレームの順序、余韻、10秒周期は維持します。
蒼閃の冒頭の走行・接近は元の速度へ復元し、実行時の時間は`SwordsmanSousenTiming`で共有します。
発動前の敵集め待機は0秒とし、発動直前まで通常攻撃を継続します。
敵を前方に集める処理と範囲攻撃は蒼閃の発動中に行います。
50候補を番号付き個別画像に切り出して見比べ、17フレームを採用しました。
判定は静止画上のポーズ・剣の接続・前後の軌道を基準にした編集判断です。
実機での滑らかさを保証する動作確認は行っていません。

## 最終順序（採用一覧と同じ）

```text
file_01_f1 → file_01_f2 → file_01_f3
→ file_02_f1 → file_02_f2 → file_02_f3
→ file_02_f5 → file_03_f2
→ file_04_f1 → file_04_f2 → file_04_f3
→ file_07_f4 → file_07_f5
→ file_09_f2 → file_09_f3 → file_09_f4 → file_09_f5
```

17フレーム、1.010秒、非ループ。斬撃部分だけをさらにゆっくりに調整しています。
剣を前方へ抜くfile_02_f5（0.315秒）と右下へ斬るfile_04_f2（0.540秒）で、
通常ダメージを各1回だけ適用します。敵が倒れた場合は次の敵、残った場合は同じ敵が対象です。
敵がいなければその斬撃は空振りです。スキル発動時は通常攻撃を中断し、残りの判定は出しません。

## 切り出しと透過

全原稿は2172×724、本物のアルファチャンネルあり。黒背景を色で消していません。
`artifacts/normal_attack_review/file_XX_fN.png` は幅/5・全高による50候補。
これだけでは剣の切断・隣人の混入があるため、既存の人物抽出処理を再利用し、
採用候補だけを透過領域で補正したアトラスに格納しています。
肩より高く持ち上げる大技や、抽出が不安定な候補は除外。
描き足し・キャラクターデザイン変更・元画像の改名はしていません。
共通キャンバスと腰の横位置・足元の基準で透明余白を合わせています。
本来の脚や上体の姿勢差は残します。

## 実装コードと組み込み

- `swordsman_normal_attack_sequence.dart`: 採用ID、速度、斬撃タイミング、run用IDの唯一の定義。
- `swordsman_run_attack_assets.dart`: 既存ローダーを更新。採用IDだけを`attackFrames`へ並べ、`SpriteAnimation.variableSpriteList(loop: false)`で生成。
  `loadSourceCandidates(game)`には10原稿を明示順で読み込み、幅/5・全高で50候補を識別するDartコードも用意。
  実際の戦闘では切断を防ぐ補正済みアトラスを使用し、除外画像をアニメーションへ入れません。
- `hero_component.dart`: 既存のrunAttack状態を再利用。非ループ再生後にrunへ戻す。走行ポーズを開始・接続・終了に残し、背景や敵の移動処理を停止させる指示や大技エフェクトを加えない。
- `battle_state_controller.dart`: 既存の自動攻撃を二連斬り開始へ接続。時間に合わせて2回のHP処理。スキルと重複不可。
- `scripts/build-swordsman-normal-attack.py`: 原稿の同名コピー、50候補生成、人物切り出し、採用アトラス生成。
- `mobile/pubspec.yaml`: 新規アセットディレクトリ登録。

既存`FocusQuestBattleGame`は同じローダーとHeroを使用しているため、別Playerを新設する必要はありません。
明示的に通常攻撃を開始する例（通常は既存の自動戦闘が呼びます）:

```dart
final started = hero.playNormalAttack();
// または battleState.playNormalAttack();
// false: 通常攻撃/スキル再生中、または集中終了済み。
```

速度は`stepTimes`だけ変更できます。フレーム採用を変更する場合はIDを編集して生成スクリプトを再実行してください。
実装後のテスト・静的解析・実機確認・Androidインストールは行っていません。
