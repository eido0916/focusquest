# Party original keyframes

Source: `art/workspace_materials/FocusQuest_pixel_keyframes_v010/`.
These PNGs are unmodified copies of the completed transparent 128×128 originals.
`catalog.json` contains the source animation metadata, hold ticks, and coordinate events.
Runtime draws one original at a time. There is no morphing, interpolation, rotation,
stretching, or fading. `scripts/build-party-assets.py` rebuilds and verifies every
copy against the source file and its recorded RGBA SHA256 hash.

The single-player animations and the source production materials are preserved.
